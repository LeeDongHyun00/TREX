기존 ImageGen 시안의 시작·끝 자세를 번갈아 보여주는 GIF(640×640, 2프레임)다.
연속 촬영 영상이나 전문가 검수를 거친 운동 교육 자료가 아니다. 로컬 작업에서
배치·재생·일시정지 동작을 확인하기 위한 자산이며, 배포용 연속 동작 시범으로 교체할 여지가 있다.
원본 파일과 바이트가 동일하다. `outputs/`는 Git 추적 대상이 아니므로 앱 실행은 여기에 복사한 파일만 사용한다.

바벨 스쿼트·바벨 컬·바벨 런지에 이 파일을 대신 쓰지 않는다.
새 자산을 넣을 때 `ExerciseGuides`에 정확한 종목 이름과 파일 경로를 등록한다.
동작 그림의 각도는 촬영 방향 안내 또는 자세 판정의 근거로 사용하지 않는다.

## 추가 4종목 (2026-10-06)

내장 `image_gen`으로 종목마다 준비/수행 자세의 두 패널 이미지를 생성했다.
두 정사각형 패널을 분리해 640×640으로 축소하고, 각 900ms·무한 반복·2프레임 GIF로 저장했다.
시작/끝 자세를 번갈아 보여 주는 기존 방식이며 연속 동작 영상은 아니다.
원본은 `outputs/exercise-guides-expansion/sources.json`, 파일 검사와 검토 이미지는 같은 폴더에 있다.
설명 근거와 맨몸 동작으로 적용한 범위는 `docs/EXERCISE_GUIDE_UI.md` §91에 기록한다.

생성 프롬프트의 공통 조건: 흰 배경의 동일 인물·고정 카메라·전신 2패널,
회색 해부학 모델·검은 반바지·맨발·주요 근육의 붉은 강조, 글자·로고·장비 없음.
종목별 동작 조건은 다음과 같다.

- 크로스 런지: 가슴 앞 두 손, 선 자세 → 한 발을 반대쪽 뒤로 교차해 양 무릎을 굽힘.
  앞발 접지, 뒤쪽 앞꿈치 접지, 앞쪽 무릎과 발끝 정렬, 몸통을 세운 사선 보기.
- 사이드 런지: 가슴 앞 두 손, 선 자세 → 오른쪽으로 디디며 오른 무릎을 굽힘.
  반대 다리는 길게, 엉덩이는 뒤로, 양발 접지, 정면 보기.
- 스탠딩 니업: 허리에 두 손, 선 자세 → 한 무릎을 앞쪽 골반 높이로 들어 올림.
  반대발 접지, 몸통을 세움, 사선 보기.
- 스탠딩 사이드 크런치: 귀 옆에 손끝, 선 자세 → 무릎을 옆으로 들고 같은 쪽 팔꿈치를 가까이.
  옆으로 몸통 굽힘, 지지발 접지, 목을 당기거나 몸통을 비틀지 않음, 정면 보기.
