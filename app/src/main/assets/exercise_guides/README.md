움직이는 9종목은 ImageGen 시안의 시작·수행 자세를 번갈아 보여주는 GIF(640×640, 2프레임)다.
플랭크는 사용자 선택에 따라 기존 GIF 첫 프레임만 사용하는 640×640 정지 PNG다.
연속 촬영 영상이나 전문가 검수를 거친 운동 교육 자료가 아니다. 로컬 작업에서
배치·재생·일시정지 동작을 확인하기 위한 자산이며, 배포용 연속 동작 시범으로 교체할 여지가 있다.
기존 스쿼트·런지·덤벨 컬은 로컬 원본 GIF를 그대로 복사했다. 추가 종목은 생성 PNG를 두 프레임으로 나누어 패키징했다.
플랭크 PNG는 최종 GIF 첫 프레임의 디코드 픽셀을 그대로 저장했으며 재생하지 않는다.
`outputs/`는 Git 추적 대상이 아니므로 앱 실행은 이 폴더의 파일만 사용한다.

바벨 스쿼트·바벨 컬·바벨 런지에 이 파일을 대신 쓰지 않는다.
새 자산을 넣을 때 `ExerciseGuides`에 정확한 종목 이름과 파일 경로를 등록한다.
동작 그림의 각도는 촬영 방향 안내 또는 자세 판정의 근거로 사용하지 않는다.

## 추가 4종목 (2026-10-06)

내장 `image_gen`으로 종목마다 준비/수행 자세의 두 패널 이미지를 생성했다.
두 정사각형 패널을 분리해 640×640으로 축소하고, 각 900ms·무한 반복·2프레임 GIF로 저장했다.
시작/끝 자세를 번갈아 보여 주는 기존 방식이며 연속 동작 영상은 아니다.
원본은 `outputs/exercise-guides-expansion/sources.json`, 파일 검사와 검토 이미지는 같은 폴더에 있다.
설명 근거와 맨몸 동작으로 적용한 범위는 `docs/EXERCISE_GUIDE_UI.md` §91에 기록한다.

생성 프롬프트의 공통 조건: 흰 배경의 동일 인물·고정 카메라·전신 2패널,
회색 해부학 모델·검은 반바지·맨발·주요 근육의 붉은 강조, 글자·로고·장비 없음.
종목별 동작 조건은 다음과 같다.

- 크로스 런지: 가슴 앞 두 손, 선 자세 → 한 발을 반대쪽 뒤로 교차해 양 무릎을 굽힘.
  앞발 접지, 뒤쪽 앞꿈치 접지, 앞쪽 무릎과 발끝 정렬, 몸통을 세운 사선 보기.
- 사이드 런지: 가슴 앞 두 손, 선 자세 → 오른쪽으로 디디며 오른 무릎을 굽힘.
  반대 다리는 길게, 엉덩이는 뒤로, 양발 접지, 정면 보기.
- 스탠딩 니업: 허리에 두 손, 선 자세 → 한 무릎을 앞쪽 골반 높이로 들어 올림.
  반대발 접지, 몸통을 세움, 사선 보기.
- 스탠딩 사이드 크런치: 귀 옆에 손끝, 선 자세 → 무릎을 옆으로 들고 같은 쪽 팔꿈치를 가까이.
  옆으로 몸통 굽힘, 지지발 접지, 목을 당기거나 몸통을 비틀지 않음, 정면 보기.

## 바닥 3종목 (2026-10-09)

내장 `image_gen`을 사용했다. 기존 `standing-side-crunch.gif` 첫 프레임을 스타일 참고로
흰 배경·회색 해부학 인물·검은 반바지·맨발·복부의 절제된 붉은 강조를 맞췄다.
측면에 가까운 사선 구도, 얇은 회색 매트, 동일 인물·카메라·조명·크기의 두 정사각형 패널,
전신이 들어가는 여백을 요청했다. 글자·화살표·로고·장비는 넣지 않았다.

- 크런치: 무릎 굽힘·발 접지·귀 옆 손끝의 누운 자세 → 상부 등을 작게 말아 올린 자세.
  발·골반을 바닥에 두고 손으로 목을 당기거나 앉은 자세로 올라가지 않도록 요청했다.
- 레그 레이즈: 등을 대고 누워 두 다리를 나란히 편 자세 → 두 다리를 함께 들어 올린 자세.
  머리·어깨·몸통 접지, 양 다리 구분, 자연스럽게 편 무릎, 골반을 말아 올리지 않도록 요청했다.
- 플랭크: 두 패널 모두 전완과 발끝으로 지지하는 유지 자세다.
  팔꿈치를 어깨 아래에 두고 지지점·전신 정렬을 유지하며 아주 작은 자연스러운 호흡 변화만 요청했다.
  준비↔유지나 팔굽혀펴기로 번갈아 보이지 않게 했다.

생성된 1774×887 PNG를 동일한 두 정사각형으로 분리해 640×640으로 축소했다.
두 프레임의 공통 256색 팔레트, 각 900ms·무한 반복·2프레임 GIF로 패키징했다.
900ms는 표시 간격이며 운동 속도·호흡 주기 처방이 아니다. 생성 그림은 연속 동작·전문가 검수 자료가 아니다.

전체 프롬프트와 원본 출처는 `outputs/core-exercise-guides/sources.json`, 패키징 스크립트는
같은 폴더의 `package_assets.py`, 프레임 검토 이미지는 `review.png`, 파일 검사 결과는 `verification.json`이다.
문구 근거·적용 범위는 `docs/CORE_EXERCISE_GUIDE_DESIGN.md` §4, 구현 기록은 §9와 정본 스펙 §103를 참조한다.
파일 디코드·메타데이터·종목 연결과 후속 JVM 테스트·APK 빌드·폰 업데이트 설치를 확인했다(설계 문서 §10).
첫 프레임 PNG 전환 기록은 설계 문서 §11에 남긴다. 실휴대폰 화면 검증은 사용자 담당이다.
