# Android 체험판 TREX v1.4 (1.4.0)

2026-11-01 · 브랜치 `feature/curl-one-tier-and-four-exercises`(PR #61) · 태그 `v1.4.0`

[GitHub 사전 릴리스](https://github.com/LeeDongHyun00/TREX/releases/tag/v1.4.0)로 공개했습니다.
빌드 소스 커밋은 `b2dd0f2a86d20cc1d87f9e315d67386491dfa2da`입니다.

preview.7(10-10) 이후의 자세 교정·운동 가이드·커뮤니티·로그인 변경을 모은 체험판입니다.
패키지는 `com.example.trex_kotlin`, versionCode는 **15**이며 Android 8.0 이상에서 설치할 수 있습니다.

## 자세 교정

- 카메라 자세 교정을 **16종목**으로 정했습니다. 나머지 10종목은 수동 기록으로 남습니다.
- **덤벨 컬은 1단 검사**입니다. 상체 숙임·옆 벌림·앞 이탈·몸에서 떨어짐이 코칭 띠에 들면 COACH 횟수에서 뺍니다.
- 굿모닝·푸시업·프런트 레이즈·사이드 레터럴 레이즈에 반복 검사와 카운터 신호를 넣었습니다. 반복 검사는 검증 중(beta)입니다.
- 뼈대·화살표 색이 결과를 말합니다. 빨강은 회에서 뺀 사유, 주황은 말했지만 센 사유, 호박은 참고입니다.
- 운동 화면의 작은 '참고' 글자 칩을 뺐습니다. 검증 중인 판정은 뼈대 호박색과 완료 화면에 남습니다.
- 덤벨·바벨 컬과 런지 네 종목의 준비 카드에 옷 안내를 넣었습니다. 통 큰 소매·펑퍼짐한 바지는 팔꿈치·무릎 위치를 잘못 읽게 합니다.

## 운동 가이드·화면

- 자세 교정 16종목 모두에 운동 방법 안내(시작 자세·동작·호흡·주의)와 시범 그림이 있습니다.
- 근육 보기·7일 기록·메인 탭 스와이프·펼침 시트·대체 운동 추천을 다듬었습니다.
- 운동 준비·진행 제어판을 새로 그렸고, 탭 전환과 세션 시계의 버벅임을 줄였습니다.
- 설정 화면의 버전이 설치된 앱의 버전을 보입니다.

## 커뮤니티·로그인

- 커뮤니티 탭(피드·글쓰기·댓글·프로필·신고)과 오운완 카드, 루틴 공유 링크가 들어왔습니다.
- 아이디 로그인과 Google·Apple 로그인을 지원합니다. Apple 로그인은 Android 에서 웹 흐름을 씁니다.

## 업데이트

기존 체험판과 같은 개발 인증서로 서명합니다. 앱 내 업데이트는 `BUILD_INFO.json` 의 versionCode 가 설치본보다 클 때 안내합니다.
versionCode 15 는 preview.7(12)과 그 뒤 내부 빌드(13·14)보다 커서 기존 체험판 어디서든 안내가 뜹니다.
같은 서명 앱 위에 업데이트하면 기존 기록이 남습니다. Google Play 로 설치한 앱은 서명이 달라 이 APK 로 덮어쓸 수 없습니다.

- 마지막 확인 이후 **6시간 이상** 지난 상태에서 앱을 새로 실행하면 확인합니다. 네트워크 연결이 필요합니다.
- 운동 중·완료 화면·세부 화면에서는 확인과 대화상자 표시를 보류합니다.
- **업데이트**를 누르면 APK를 내려받아 해시를 확인한 뒤 Android 설치 화면을 엽니다.

릴리스 자산은 `TREX-1.4.0.apk`, `SHA256SUMS.txt`, `BUILD_INFO.json`입니다.
배포 빌드(`-Ptrex.distribution=true`)라 세트 로그·자가 라벨·횟수 검증 모드 같은 실검증 도구는 꺼져 있습니다.

## 검증 범위와 남은 확인

로컬 앱 JVM 단위 테스트 **915건**이 통과했습니다. 실패·오류·건너뜀은 0건이며 `:app:assembleRelease`와 release 필수 lint 검사가 성공했습니다.
APK 의 패키지·versionCode 15·버전 이름 1.4.0 과 서명 인증서를 확인했습니다. 인증서 SHA-256 은 preview.6·7 과 같습니다:
`3027771596e23100d4203da03cd44c4a81f5e3d4cf197fdb7fb2ba4e4dc751ef`.
APK SHA-256: `332497558e265b191ac2d1da09019d440a029d547a648fe0e6bd4b575e4eb523`.
업로드한 자산의 해시가 로컬 원본과 일치하는 것을 확인했습니다.
같은 커밋의 디버그 빌드를 폰(SM-N976N)에 설치해 dex 검증을 통과했습니다. 배포 APK 의 폰 설치와 실제 운동 세션 검증은 하지 않았습니다.
iPhone 은 이 릴리스에 포함되지 않습니다.

일부 자세·판별 기준은 폰 라벨 검증 중입니다. 관절 추정의 가림·좌우 뒤바뀜·촬영 배치·헐렁한 옷 때문에
반복이나 유지 시간이 실제 수행과 다를 수 있습니다. 덤벨 컬 1단과 스쿼트 무릎 벌림 차단은 사용자 정의 기준이라 일부 정상 수행도 횟수에서 뺄 수 있습니다.

설계·구현 근거는 정본 스펙 §107~§129 에 있습니다.

## 문제 발생 시

설치 불가·앱 실행 불가·기록 손실이 확인되면 릴리스를 초안으로 전환해 앱 내 업데이트 노출을 중단합니다.
기록을 보존하면서 같은 서명의 더 높은 버전 코드 수정판을 배포합니다.
