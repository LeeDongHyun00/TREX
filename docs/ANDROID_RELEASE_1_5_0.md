# Android 체험판 TREX v1.5 (1.5.0)

2026-11-07 · 브랜치 `main`(PR #64 "trex v1.5", PR #65·#66 포함) · 태그 `v1.5.0`

[GitHub 사전 릴리스](https://github.com/LeeDongHyun00/TREX/releases/tag/v1.5.0)로 공개합니다.
빌드 소스 커밋은 `3efe6a564f188cee2ee9aa3b0e6f75c1debb9437`입니다.

v1.4(11-01) 이후의 운동 카탈로그 확장·기록 화면·가이드·보상 변경을 모은 체험판입니다.
패키지는 `com.example.trex_kotlin`, versionCode는 **16**이며 Android 8.0 이상에서 설치할 수 있습니다.

## 운동 카탈로그·가이드

- 운동이 **72종목**으로 늘었습니다(AIHub 26 + 자세 평가 없는 46). 새 46종은 카메라 자세 교정 없이 기록·근육 부하만 됩니다(스펙 §130).
- 72종목 전부에 운동 가이드(시범 GIF·시작 자세·동작·호흡·주의)가 있습니다. 13종 그림을 눈으로 검수해 고쳤고, 가이드 시트는 가이드·주의 두 탭입니다(§135·§136).
- 맨몸 종목의 kg 은 **추가 중량(+kg)** 입니다. 체중은 풀업·딥스에서만 볼륨에 들어가고, 1RM 추정은 외부 중량 종목에만 있습니다(§134).

## 기록 화면

- 세트 기록(kg·회·RPE·메모), 월 달력, 업적·레벨, 체중 기록, 2층 카탈로그, 루틴 추천(초보/전체·장비·부위), 설정·물 카드가 들어왔습니다(§131·§132).
- 홈은 '오늘 한눈' 띠(운동 세트·섭취 kcal·탄단지 링·물 잔)와 근육 글리프로 바뀌었습니다(§133·§134).
- 종목 상세는 '사용 근육'(2D 근육도)이 맨 위이고, 근거가 약한 종목은 '추정' 칩으로 밝힙니다.
- **소모 kcal 식이 바뀌었습니다** — 종목별 MET(2024 Adult Compendium) × 체중 × 휴식 포함 시간. 옛 식으로 적힌 기록은 첫 실행 때 같은 식으로 고쳐 적습니다. 완료 화면 ⓘ·기록 통계 배너에 식·출처·쓰인 체중을 적어 두었습니다(§134b).

## 보상·세션

- 배지가 22개로 바뀌었습니다(운동 일수 사다리·완벽한 주/달·아침/저녁 운동·볼륨 10톤·식단 30일·물·체중 등). 첫 PR 배지는 뺐습니다. 아이콘으로 그립니다(§137·§138).
- 완료 화면의 경험치 바가 차오르는 애니메이션으로 바뀌었습니다.
- **건너뛴 세트는 사용자가 횟수를 적은 것만** 기록·근육 피로도에 들어갑니다. 카메라가 센 회·계획 횟수는 건너뛴 세트의 증거로 쓰지 않습니다(§138).
- 세션 화면의 '이 회 제외' ✕ 배지·세트 점, 휴식·완료 화면 재배치(§125b·§133).

## 날씨·기타

- 홈 날씨 줄에 Open-Meteo 날씨와 AQICN 미세먼지를 함께 보여 주고, 미세먼지에 따라 실내·실외 추천을 바꿉니다(PR #64).

## 업데이트

기존 체험판과 같은 개발 인증서로 서명합니다. 앱 내 업데이트는 `BUILD_INFO.json` 의 versionCode 가 설치본보다 클 때 안내합니다.
versionCode 16 은 v1.4(15)보다 커서 기존 체험판 어디서든 안내가 뜹니다.
같은 서명 앱 위에 업데이트하면 기존 기록이 남습니다. Google Play 로 설치한 앱은 서명이 달라 이 APK 로 덮어쓸 수 없습니다.

릴리스 자산은 `TREX-1.5.0.apk`, `SHA256SUMS.txt`, `BUILD_INFO.json`입니다.
배포 빌드(`-Ptrex.distribution=true`)라 세트 로그·자가 라벨·횟수 검증 모드 같은 실검증 도구는 꺼져 있습니다.

**옛 앱 주의** — v1.4 이전 앱이 서버 백업의 `history` 를 저장하면 세트 기록(`sets`·`bw`)이 지워지고 kcal 이 옛 식으로 돌아갑니다(`docs/SERVER_REQUIREMENTS_PAGES_V2.md` §4). 업데이트 안내를 따라 주세요.

## 검증 범위와 남은 확인

로컬 앱 JVM 단위 테스트 **936건**이 통과했습니다. 실패·오류·건너뜀은 0건이며 `:app:assembleRelease`(release 필수 lint 포함)가 성공했습니다.
APK 의 패키지·versionCode 16·버전 이름 1.5.0 과 서명 인증서를 확인했습니다. 인증서 SHA-256 은 v1.4 와 같습니다:
`3027771596e23100d4203da03cd44c4a81f5e3d4cf197fdb7fb2ba4e4dc751ef`.
APK SHA-256: `1f96db040f209ccf1e2fa9af80048ac88b6d87341f30b403afe60bc266f25908`.
같은 소스의 디버그 빌드를 폰(SM-N976N)에 설치해 홈·기록·업적·세트 입력 화면과 dex 검증을 확인했습니다. 배포 APK 의 폰 설치와 실제 운동 세션 검증은 하지 않았습니다.
iPhone 은 같은 커밋을 Actions `iOS App Store 업로드`로 올립니다(별도 승인).

카메라 자세 교정은 v1.4 와 같은 16종목이고, 일부 판정 기준은 폰 라벨 검증 중입니다. 관절 추정의 가림·좌우 뒤바뀜·촬영 배치·헐렁한 옷 때문에
반복이나 유지 시간이 실제 수행과 다를 수 있습니다. 소모 kcal·근육 피로도는 추정값입니다.

설계·구현 근거는 정본 스펙 §130~§138 에 있습니다.

## 문제 발생 시

설치 불가·앱 실행 불가·기록 손실이 확인되면 릴리스를 초안으로 전환해 앱 내 업데이트 노출을 중단합니다.
기록을 보존하면서 같은 서명의 더 높은 버전 코드 수정판을 배포합니다.
