# 독립 엔진 실험 앱 — 2026-09-19 (§59)

사용자는 기존 앱 이식보다 이 대화에서 개발한 엔진 자체 검증을 우선하도록 요청했다.
기존 `.replay` 앱에는 새 복귀·좌우 카운터가 실제 연결됐지만, 자세 판정은 기존 `LiveCoach`와 규칙셋이었다.
따라서 그 앱을 독립 엔진 앱이라고 설명할 수 없다. 앱 이름이나 버전 배지만 바꾸는 것도 독립성 확보가 아니다.

새 [engine-lab](../engine-lab/README.md)은 별도 Gradle 루트와 `com.trex.engine.lab` 패키지를 사용한다.
순수 JVM `:engine`과 카메라/저장 UI `:app`만 있으며 상위 제품 앱 프로젝트에 의존하지 않는다.
이 대화의 복귀 FSM·좌우 추적·26종 프로필을 가져오고, 기존 `RepCounter` 래퍼를 제거했다.
기존 관절 수학과 촬영 방향 수식·MediaPipe 모델을 재사용한 출처는 소스 목록으로 남겼다.
`LiveCoach`, `PostureRuleSet`, 기존 앱 클래스와 자세 규칙 자산은 APK에 포함하지 않는다.

화면은 운동/방식 선택, 전면 카메라, 관측 횟수와 측, 관절 기하 값, 구현 범위, 실제 횟수·메모, ZIP 공유로 구성한다.
25종 왕복 카운트와 플랭크 관측 시간을 실행한다. 미관측을 정상 점수로 표시하지 않는다.
147개 자세 항목은 연구 설계이며 새 독립 자동 판정·교정 코드가 아직 없다.
이 범위는 화면과 로그의 `RESEARCH_MEASUREMENTS_ONLY`, `automatic_correction_enabled=false`로 명시한다.

로그는 33점의 미러 전 원본 좌표와 월드 좌표·가시성, 입력 피처, 카운트/측/이벤트, 보류 사유와 모델 실행 시간을 보존한다.
엔진 소스 SHA-256, 모델 SHA-256, 앱/모델 버전, 카운터 파라미터를 함께 남긴다.
수동 횟수 정답과 의도적 변형 메모는 별도 레코드다. 지시한 횟수를 실제 정답으로 기록하지 않는다.
사진/영상이나 계정·네트워크 전송 기능은 없다. 공유 대상은 Android 공유 창에서 사용자가 선택한다.
USB 회수/ZIP 분석은 `engine-lab/tools/inspect_logs.py`로 수행한다.

검사 범위:

- JVM 74건: 복귀·가림·시간 역행·양측/교대, 26 프로필, 방향 회복, 바닥 유지, 기하 계산과 기존 연구 픽스처 일치.
- `LabDeviceTest` 3건: 독립 패키지/기존 클래스 부재, 실제 이미지 MediaPipe 추론, 합성 로그 재생/ZIP/FileProvider 읽기.
- `SavedSessionsReplayTest`: 실제 앱 세션이 생긴 뒤 원시 관절에서 피처를 재계산하고 매 프레임 출력 일치를 검사한다.
- 실제 UI 검사는 휴대폰 잠금 해제 후 진행한다. 테스트 완료 상태와 설치 해시는 Codex 산출물 `outputs/engine-lab/verification.json`에 남긴다.

이 검사는 실험 도구의 연결·재현성을 확인한다. 26종 실제 사람의 반복 정확도, 잘못된 자세의 오탐/누락률, 교정 효과를 검증한 결과가 아니다.
새 앱에서 정답 라벨이 있는 실험을 모아 실패를 재현한 뒤에만 기존 TREX에 이식한다.

## Git 업로드 시점의 남은 작업

사용자는 현재 구현을 먼저 Git에 올리도록 요청했다. 기능 완성 선언이 아닌 개발 체크포인트다.
사람의 실제 운동 검증은 요청하지 않고 이미지·기록 재생과 자동 검사로 진행한다.
휴대폰 잠금은 해제됐고 독립 앱 화면을 확인했다. UI 계층에서 하단 시작 버튼의 일부 잘림이 발견됐으며,
수정 및 실제 카메라 기록·공유 UI 검사는 아직 완료하지 않았다. 이 상태를 숨기거나 검사 완료로 간주하지 않는다.
