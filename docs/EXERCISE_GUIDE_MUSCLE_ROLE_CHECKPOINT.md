# 운동 가이드 근육 표시 중간 점검

후속 결과: 72종의 주된 동작·보조·지지 역할과 근거를 다시 작성하고, 기존 앱 GIF를 직접 열어 확인한 빨강·주황 기준으로 72종을 재제작했습니다. [역할별 설명표](../research/exercise_guides/guides.ko.json)와 [수정본 검토 화면](EXERCISE_GUIDE_APP_72.md)이 최신 자료입니다. 원본 및 260px 크기에서 검토했고, 근육 위치·힘줄 경계·교대 동작 오류를 수정했습니다. 아래 단색 초안 관련 내용은 최초 점검 당시의 기록입니다.

제작 단계 검사: 72개 GIF 모두 640×640, 자세당 900ms, 무한 반복입니다. I/Y/T는 3프레임, 나머지는 2프레임이며 총 145프레임을 디코드했습니다. 파란색 잔여 픽셀 검사와 72개 이미지의 브라우저 로딩, 검색 및 모바일 가로 넘침 검사를 통과했습니다. 문헌·시각 검토는 의료 전문가의 임상 인증을 뜻하지 않습니다. 이 시점에는 앱 통합 전이었습니다. 이후 앱 반영·빌드·에뮬레이터 검증 결과와 휴대폰 검사 대기 상태는 [앱 통합 기록](EXERCISE_GUIDE_APP_72.md)에 정리했습니다.

## 기존 이미지 기준으로 확정한 표시 정책

- `app/src/main/assets/exercise_guides/`의 스쿼트·푸시업·플랭크·크런치·레그 레이즈·레터럴 레이즈 원본 프레임을 직접 확인했습니다.
- 빨강은 주요 강조 부위, 주황은 함께 작용하는 부위입니다. 파랑을 도입한 중간 시안은 최종 기준에서 제외했습니다.
- 색과 실제 기능을 별도로 관리합니다. 플랭크의 복직근처럼 정적 지지가 핵심인 부위도 빨강일 수 있습니다. 주황 부위의 보조·지지 기능은 근육별 설명에서 구분합니다.
- 기존 레그 레이즈·니업의 대퇴직근 빨강 표시를 유지하되, 장요근과 대퇴직근의 기능 관계는 자료에 따라 설명합니다. 색을 근전도 크기·근육 성장 효과의 순위로 해석하지 않습니다.
- 플랭크의 전면 삼각근과 사이드 플랭크의 지지측 삼각근에 대한 직접 측정 근거를 추가했습니다. 무릎 변형은 직접 측정과 구분해 적용합니다. [플랭크 연구](https://dergipark.org.tr/en/download/article-file/3373394) · [사이드 브리지 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC9312545/)
- 깊은 근육·옷에 가린 근육·카메라 반대편 근육은 다른 표면 부위에 대신 칠하지 않습니다. 누락 사유와 실제 역할은 설명과 검토 기록에 남깁니다. 회색은 비활성을 뜻하지 않습니다.

2026-11-07. 사용자 요청에 따라 신규 이미지 생성을 중단하고 단색 초안의 누락을 점검했습니다.

## 판단

기존 검토는 근거가 있는 일부 표층 근육만 골라 표시하는 데 집중했습니다. 따라서 72종의 출처를 확인한 것과, 각 운동의 주요 동작근·보조근·지지근을 빠짐없이 검토한 것은 다릅니다. 현재 초안은 후자를 충족하지 않습니다.

회색인 팔과 다리를 비활성 부위로 오해할 수 있습니다. 실제로 측정 근거가 있는데도 보수적인 부분집합이라는 이유로 생략한 근육이 있습니다. 이것은 표시 정책의 부족이며, 다른 색을 사용할 수 없다는 의학적 결론이 아닙니다.

## 수정할 기준

1. 운동의 실제 관절 동작부터 정의하고 주요 동작근·협력근·자세 지지근을 각각 조사합니다. 운동 카테고리 이름으로 역할을 결정하지 않습니다.
2. 역할별 색은 사용할 수 있습니다. 다만 색을 근전도 크기·강도 순위·성장 효과로 해석하지 않도록 범례를 명확히 합니다. [근전도 해석 방법론](https://pmc.ncbi.nlm.nih.gov/articles/PMC5758546/)
3. 직접 측정, 유사 변형 연구, 의학 해부학에 근거한 추론을 계속 구분합니다. 단순히 팔·다리가 움직인다는 이유만으로 전체 부위를 칠하지 않습니다.
4. 깊은 근육은 피부 표면의 다른 근육 위에 칠하지 않습니다. 옷에 가린 근육도 삭제하지 않고 이름·역할 또는 별도 해부학 설명으로 다룹니다.
5. 이미 만든 단색 자산은 재사용 가능한 자세 시안으로 보존합니다. 근육 역할 검토가 끝나기 전까지 최종 근육 안내 자산으로 승인하거나 앱에 적용하지 않습니다.

## 최초 점검 당시 상태

- 기존 72종 출처 감사는 제한된 표층 근육 부분집합에 대한 자료입니다.
- 주요·보조·지지 근육 전체의 역할 검토는 미완료입니다.
- 현재 GIF는 단색 초안이며, 일부 교대 동작 자세도 미해결입니다.
- 앱 구현·기존 앱 자산 교체·배포는 하지 않았습니다.
