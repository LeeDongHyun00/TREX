# Android 체험판 1.3.0-preview.8

커뮤니티·루틴 공유·계정 로그인과 기록 백업을 더한 체험판입니다.
이 버전부터 운동 세트의 관절 좌표 기록·음성 기록·자가 라벨 입력을 넣지 않은 배포 빌드로 냅니다.
- 커뮤니티 탭: 사진 글·좋아요·댓글, 운동 완료 화면의 오운완 카드
- 루틴 공유: 링크로 보내고 받기, 내 루틴 보관함
- 로그인: 아이디·Apple·Google 계정으로 운동·식단 기록을 서버에 백업
- 홈 날씨와 추천 운동, 근육 피로도 목록·2D 근육도, 새 운동 제어판

2026-10-30 · `main` 기준 · 태그 `v1.3.0-preview.8`
패키지 `com.example.trex_kotlin`, versionCode **13**, Android 8.0 이상

## 커뮤니티

- 하단 탭이 홈 · 운동 · 식단 · **커뮤니티** · 내 정보가 됩니다. 커뮤니티를 보고 쓰려면 로그인하고 닉네임·이용규칙 동의를 마쳐야 합니다.
- 글에 사진을 5장까지 붙일 수 있습니다(갤러리·카메라, 긴 변 1080px JPEG로 줄여 올림). 피드는 전체 최신순이고 좋아요·댓글·프로필·신고·차단이 있습니다.
- 운동 완료 화면의 **오운완 올리기**는 횟수·시간 같은 숫자만 담은 카드를 만듭니다. 자세 판정은 카드에 넣지 않습니다.
- 올린 글과 사진은 서버에 저장되고, 회원 탈퇴 때 함께 지웁니다.

## 루틴 공유

- 운동 탭의 **루틴 공유**로 루틴 링크를 만들어 메신저로 보냅니다. 링크는 웹 페이지로 열리고, 앱이 있으면 **앱에서 열기**로 받은 루틴 화면을 엽니다.
- 보내려면 로그인과 커뮤니티 준비(닉네임·이용규칙)가 필요합니다. 보낸 사람 이름은 커뮤니티 닉네임입니다.
- **내 루틴** 보관함에 루틴을 저장해 두고 다시 불러옵니다. 커뮤니티 글도 같은 링크로 공유하며, 글 내용은 앱 안에서만 보입니다.

## 로그인과 기록 백업

- 시작 화면은 **아이디로 로그인 · Apple로 계속하기 · Google로 계속하기 · 로그인 없이 사용**입니다. 로그인하지 않아도 커뮤니티·공유를 뺀 기능을 모두 씁니다.
- 아이디 가입에는 개인정보 처리방침 동의가 필요하고 비밀번호 찾기는 없습니다. 5번 연속 틀리면 10분 동안 잠깁니다.
- Apple 로그인은 Android에서 Apple 웹 로그인 화면을 거쳐 앱으로 돌아옵니다.
- 로그인하면 프로필·운동 계획·운동 기록·식단·물·직접 등록한 음식·영양 목표를 서버에 백업하고, 앱을 다시 설치하거나 기기를 바꿔도 이어 씁니다. 이 기기와 서버 양쪽에 기록이 있으면 어느 쪽을 쓸지 묻습니다.
- 자세 기준선과 음식 사진 기억은 서버로 보내지 않습니다.
- 설정의 계정 줄에 로그인 방법이 보이고 지금 동기화·로그아웃·회원 탈퇴를 할 수 있습니다. 탈퇴하면 서버의 계정·백업·커뮤니티 글을 지우고 기기의 기록은 남깁니다.
- preview.7을 쓰던 기기는 시작 화면을 다시 거치지 않습니다. 설정이나 커뮤니티 탭에서 계정을 연결합니다.
- 개인정보 처리방침: <https://leedonghyun00.github.io/TREX/privacy.html>

## 화면

- 홈 날짜 아래에 날씨 한 줄(지역·기온·하늘·강수량)이 생겼고, 누르면 날씨에 맞는 추천 운동과 출처를 보여 줍니다. 날씨는 Open-Meteo에서 받습니다. 지역을 고르거나, 위치 권한을 허용해 현재 위치를 씁니다.
- 근육 피로도는 피로도가 있는 근육만 높은 순 목록과 앞·뒷면 2D 근육도로 보여 줍니다. 운동 기록과 같은 오늘 포함 7일 기록을 씁니다.
- 메인 탭을 좌우로 밀어 넘길 수 있습니다.
- 운동 준비·진행 제어판을 새로 그렸습니다 — 세 칸 수치와 원형 버튼(나가기·음성·건너뛰기·카메라·일시정지).
- 플랭크는 운동 편집에서 시간 목표만 고릅니다.
- 식단 인분을 0.5 단위로 조절하고, 숫자를 누르면 소수 한 자리까지 직접 입력합니다.
- 바텀 시트의 펼침·끌어 닫기 동작을 통일했습니다. 앱 아이콘을 공룡 로고로 바꿨습니다.
- 설정의 버전 줄이 설치된 앱의 버전(`1.3.0-preview.8 (13)`)을 보여 줍니다.
- release 빌드를 R8로 최적화하고 Baseline Profile을 넣어 화면 구성 비용을 줄였습니다. APK가 153MB에서 141MB로 줄었습니다.

## 실검증 기록을 뺀 배포 빌드

- 이 APK는 `-Ptrex.distribution=true`로 만든 배포 빌드입니다(`BuildConfig.DEV_TOOLS=false`, 버전 이름에 `-dev` 없음, 스펙 §116).
- 세트 로그(`posture_logs/sets-*.jsonl`, 프레임 피처·관절 좌표)와 음성 기록(`posture_logs/feedback-*.jsonl`)을 쓰지 않고, 완료 화면의 자가 라벨 칸과 횟수 검증 모드가 없습니다. 자세 판정·횟수·음성 코칭은 개발자 빌드와 같습니다.
- preview.7까지는 모든 설치본이 이 기록을 남겼습니다. 업데이트해도 이미 남은 파일(`Android/data/com.example.trex_kotlin/files/posture_logs/`)은 지우지 않습니다. 기기 안의 앱 전용 폴더이고 서버로 보내지 않았으며, 앱을 삭제하면 함께 지워집니다.

## 자세 평가

자세 규칙·임계값·횟수 기준은 preview.7과 같습니다(규칙셋 `mp_v0.1+floor_v0.5+repform_v0.14`).
자세 화면과 분석 루프를 iPhone과 같은 코드로 옮겼고(스펙 §108c) 판정 기준은 바꾸지 않았습니다.

## 검증 범위와 남은 확인

- 앱 JVM 단위 테스트 **882건**, 재생기 테스트 **144건**, `setlog_captures.py --self-test` **54/54**가 통과했습니다. 실패·오류·건너뜀은 0건입니다.
- `:app:assembleRelease -Ptrex.distribution=true`와 release 필수 lint가 성공했습니다.
- APK의 패키지·버전 코드 13·버전 이름 `1.3.0-preview.8`(`-dev` 없음)과 `BuildConfig.DEV_TOOLS=false`를 확인했습니다. 덱스에 자가 라벨 칸·횟수 검증 모드·음성 기록 코드가 남지 않았습니다.
- v2 서명 검증을 통과했고 인증서 SHA-256이 preview.7과 같습니다.
- 에뮬레이터(Android 16, arm64 라이브러리 번역 실행)에 새로 설치해 시작 화면·온보딩·홈 날씨·커뮤니티 진입 안내·설정 버전 줄·운동 준비 화면·사진 식단 분석을 크래시 없이 확인했습니다.
- 그 확인에서 R8이 MediaPipe 초기화를 깨뜨려 카메라 자세 분석이 시작되지 않는 문제를 찾아 이 릴리스에서 고쳤습니다(스펙 §121). 고친 뒤 `PoseLandmarker` 생성까지 확인했습니다. preview.7에는 R8을 쓰지 않아 이 문제가 없었습니다.
- 에뮬레이터 GPU가 MediaPipe GPU 추론을 지원하지 않아 실제 관절 추정·횟수 세기는 확인하지 못했습니다.
- 휴대폰 설치, preview.7에서의 업데이트 설치, 운동 세션, 로그인·동기화·커뮤니티의 실제 동작은 이 릴리스에서 확인하지 않았습니다.
- Google 로그인은 이 서명 인증서의 SHA-1(`a6:95:e7:f3:0e:40:c8:62:c3:8c:2b:0b:41:a2:57:32:ea:a4:0d:c9`)이 Google Cloud 콘솔의 Android OAuth 클라이언트에 등록돼 있어야 동작합니다. 이 릴리스에서 등록 여부를 확인하지 않았습니다.

일부 자세·판별 기준은 폰 라벨 검증 중입니다. 관절 추정의 가림·좌우 뒤바뀜·촬영 배치 때문에
반복이나 유지 시간이 실제 수행과 다를 수 있으며, 깊이·허리 접지·시선의 모든 오류를 관측하지 못합니다.
로그인·커뮤니티·공유는 운영 서버(`trex-api.duckdns.org`)에 닿아야 동작합니다. 서버에 닿지 않아도 기기 기록과 운동·식단 기능은 그대로 씁니다.
