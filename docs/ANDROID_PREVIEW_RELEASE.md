## 변경 내용과 이유

기록 모드 ON/OFF 대신 **자세 교정 / 기록 모드**를 직접 고른다. 두 방식의 이름을 항상 보이고 선택 배경을 200ms 동안 이동한다. 48dp 이상 터치 영역과 접근성 이름·선택 상태를 제공한다. 준비에서만 짧게 방식의 의미를 설명하고 운동 중에는 반복 설명을 덜었다. 준비의 방향 시범 공간을 넓히고 운동 시작 후 카메라 영역을 넓힌다

홈에는 기존 카드 구성, 탄단지 비율, 남은 칼로리, 실제 운동일/활동 요약을 복구했다. 임의의 초기 출석·식단·평균값을 제거하고 실제 세트 가동 시간을 저장한다. 예전 샘플을 정리할 때는 전체 샘플 지문과 일치하는 것만 제거하며 원본을 보관한다. 날짜별 운동 기록에는 운동 중심과 판정 범위에 한정된 요약을 추가했다

운동·끼니를 누르면 편집하고 운동 길게 누르기 순서 변경·스와이프 삭제는 유지한다. 운동 카드에는 `N개 운동 · N세트 · 약 N분`을 모아 중복 요약을 없앴다. 끼니 그림은 실제 음식 예시 대신 해돋이·해·티타임·달을 사용한다. 설명은 공룡 말투로 통일하고 문장 끝 마침표를 제거하되 소수점·URL·버전은 유지한다. 로그인 로고 위치도 정렬했다

접힘 경계와 창 크기로 화면을 재배치하며 카메라 Composition은 유지한다. 준비 건너뛰기, 종목별 기록 모드 저장, 처음 자세/자동 횟수 보존은 기존 정책대로다. 판정 규칙과 자세 정확도가 개선됐다는 의미는 아니다

운동 중 제어판은 관절 관측이 안정되면 아래로 내려가고 가까이 접근하거나 화면에서 벗어나면 다시 올라온다. 3초 안정·700ms 접근·1.5초 이탈 대기와 직접 열기 후 8초 유지로 흔들림을 줄인다. 운동명·세트·횟수/원형 타이머·자세 안내와 오른쪽 하단 제어판 열기는 남긴다. 제어판 이동 중 영상 크기와 카메라 연결을 유지한다

## 업데이트와 문제 발생 시

동일 서명의 기존 설치본은 삭제 없이 업데이트한다. 기기 설치 전 기록/설정을 백업하고 첫 실행 전 바이트 보존을 확인한다. 운동 기록은 오늘을 포함한 최근 7일을 보관하며 기존 만료 정책은 유지한다

설치 실패·실행 불가·준비 탈출 불가·기록 손실이 확인되면 릴리스를 초안으로 전환해 다운로드를 중단한다. 낮은 버전 강제 설치나 앱 삭제 대신 같은 서명의 더 높은 versionCode로 수정판을 배포해 개인 기록을 보존한다
