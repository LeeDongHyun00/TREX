# Android 체험판 1.1.0-preview.2

2026-09-12 · `feature/posture-coach-reliability` · 태그 `v1.1.0-preview.2`

기존 다운로드 경로의 APK를 §54~§55 수정본으로 교체한다. 버전 이름/코드는 동일하며 태그는 최초 배포 소스를 유지한다. 갱신 APK의 정확한 소스 커밋은 GitHub 릴리스 본문에 별도로 명시한다

## 배포 대상

- 패키지 `com.example.trex_kotlin`, versionCode `3`, versionName `1.1.0-preview.2`
- Android 8.0(API 26) 이상, 기존 개발 설치본과 같은 개발 서명의 debug 미리보기 APK
- APK·SHA256SUMS는 GitHub 사전 릴리스에만 제공한다. 원본 데이터·키·개인 기기 화면/로그·기록은 공개하지 않는다

## 변경 내용과 이유

기록 모드 ON/OFF 대신 **자세 교정 / 기록 모드**를 직접 고른다. 두 방식의 이름을 항상 보이고 선택 배경을 200ms 동안 이동한다. 48dp 이상 터치 영역과 접근성 이름·선택 상태를 제공한다. 준비에서만 짧게 방식의 의미를 설명하고 운동 중에는 반복 설명을 덜었다. 준비의 방향 시범 공간을 넓히고 운동 시작 후 카메라 영역을 넓힌다

홈에는 기존 카드 구성, 탄단지 비율, 남은 칼로리, 실제 운동일/활동 요약을 복구했다. 임의의 초기 출석·식단·평균값을 제거하고 실제 세트 가동 시간을 저장한다. 예전 샘플을 정리할 때는 전체 샘플 지문과 일치하는 것만 제거하며 원본을 보관한다. 날짜별 운동 기록에는 운동 중심과 판정 범위에 한정된 요약을 추가했다

운동·끼니를 누르면 편집하고 운동 길게 누르기 순서 변경·스와이프 삭제는 유지한다. 운동 카드에는 `N개 운동 · N세트 · 약 N분`을 모아 중복 요약을 없앴다. 끼니 그림은 실제 음식 예시 대신 해돋이·해·티타임·달을 사용한다. 설명은 공룡 말투로 통일하고 문장 끝 마침표를 제거하되 소수점·URL·버전은 유지한다. 로그인 로고 위치도 정렬했다

접힘 경계와 창 크기로 화면을 재배치하며 카메라 Composition은 유지한다. 준비 건너뛰기, 종목별 기록 모드 저장, 처음 자세/자동 횟수 보존은 기존 정책대로다. 판정 규칙과 자세 정확도가 개선됐다는 의미는 아니다

카메라는 제어판 위에 영상 전체가 보이는 큰 미리보기로 배치하고, 제어판을 접으면 전체 화면으로 확장한다. 횟수·시간·목표·원형 진행률은 하단 표시줄에 모아 얼굴 앞을 비운다. 준비 5초를 마치면 제어판 없이 시작하며, 준비를 건너뛰었을 때는 전신 촬영 범위가 연속 1초 확인되면 접는다. 직접 열기와 일시정지는 조작 시간을 유지한다. 준비·평가 TTS는 일반 존댓말로 안내하며 끼니 수정의 ‘이 끼니 합계’ 문구는 제거했다

실제 사람이 전신을 맞춘 자동 접힘 성공률은 미측정이며 1초 경계·관측 끊김은 단위 검사로 확인했다. 실제 폴더블 센서와 다양한 사람/공간의 자세 정확도는 미검증이다. 사용자 요청에 따라 이번 실기기 검사는 두 항목으로 제한했다. 로그인은 서버 인증에 연결되지 않았고 사진 자동 분석은 아직 지원하지 않아 직접 음식 선택으로 기록한다. CI 검증을 주장하지 않는다

## 빌드

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest -PpostureReplay
# 분리 APK/테스트 APK를 보관한 뒤 일반 패키지로 다시 빌드
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

일반 APK는 `-PpostureReplay` 없이 빌드한다. 동일한 출력 경로를 쓰므로 분리 APK는 먼저 보관한다

## 업데이트와 문제 발생 시

동일 서명의 기존 설치본은 삭제 없이 업데이트한다. 기기 설치 전 기록/설정을 백업하고 첫 실행 전 바이트 보존을 확인한다. 운동 기록은 오늘을 포함한 최근 7일을 보관하며 기존 만료 정책은 유지한다

설치 실패·실행 불가·준비 탈출 불가·기록 손실이 확인되면 릴리스를 초안으로 전환해 다운로드를 중단한다. 낮은 버전 강제 설치나 앱 삭제 대신 같은 서명의 더 높은 versionCode로 수정판을 배포해 개인 기록을 보존한다
