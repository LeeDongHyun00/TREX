# 26종목별 단계·계수·교정 계약 초안

작성: 2026-09-23. **설계 후보이며 구현·정확도 검증 완료 목록이 아니다.**
계수 계약의 실행 버전은 `MotionContracts.kt`, 현재 구현 범위는 [M1 구현 문서](POSTURE_MOTION_ENGINE_IMPLEMENTATION.md)를 따른다. 아래 오류 후보 전체가 구현됐다는 뜻은 아니다.
상위 설계: [운동 이해·실시간 교정 엔진](POSTURE_MOTION_ENGINE_DESIGN.md).

현재 `ExerciseProfiles`의 26개 앱 이름과 정확히 대응한다. AIHub에 다른 종목이 있더라도 서비스 범위에 추가하지 않는다. 각 행의 오류 후보를 모두 AIHub가 방향별로 라벨링했다는 뜻은 아니다. 실제 description/관절/뷰/정답의 연결표를 만든 뒤 발화 가능 여부를 개별 승인한다.

## 1. 공통 계약

- **관측 1회**는 선택한 계수 지점에 도달한 운동 동작이다. 정상 자세 전체를 통과했다는 의미가 아니다.
- 스쿼트처럼 하강 후 복귀가 자연스러운 종목과 프레스처럼 힘쓰는 끝점이 자연스러운 종목의 계수 지점을 구분한다. UI의 ‘1회 기준’ 짧은 시범과 텍스트도 이 계약에서 생성한다.
- 끝점에서 세는 종목은 반대 단계로 충분히 돌아가야 다음 반복을 다시 셀 수 있다. 같은 끝점에 머물거나 떨면 중복 계수하지 않는다. 품질 평가는 계수 후의 내리기 구간까지 이어질 수 있다.
- 교대 종목은 아래의 기본 단위를 세트 시작에 고정한다. 도중에 왼쪽/오른쪽을 합치는 기준이 바뀌지 않는다. 다른 단위를 선택하게 한다면 원시 좌우 사건에서 명시적으로 환산한다.
- ‘부족’과 ‘과도’는 개인의 전체 운동 범위에서 추측하지 않고 선택 운동의 단계별 검증 범위로 판정한다. 아래의 단일 센서값은 모두 후보이며 하나만으로 정오를 확정하지 않는다.
- 아래/위, 앞/뒤, 안/밖은 카메라 화면 방향이 아니라 운동·신체·지지발 좌표다.
- 준비 자세와 실제 운동 단계가 구분되지 않으면 계수하지 않는다. 모르는 행동은 미지원 동작으로 남기고 다른 운동의 기준을 끌어오지 않는다.

## 2. 종목별 설계표

`F`: 정면 후보, `O`: 사선 후보, `S`: 측면 후보, `LS`: 낮은 측면 후보. 촬영 방향은 **관측하려는 항목 기준의 후보**다. 현행 규칙의 검증된 뷰를 이 표만 보고 확대하지 않는다. 한 대의 카메라로 한 배치에서 모든 항목을 동시에 보겠다고 약속하지 않는다.

## 3. 공통 오류를 재사용하는 조건

오류 템플릿은 이름이 아니라 **운동에서 고정해야 하는 관계**로 선택한다.

| 관측 관계 | 서로 다른 해석 예 |
|---|---|
| 팔이 몸에서 멀어짐 | 레터럴 레이즈의 의도된 움직임 / 컬의 상완 이탈 후보 |
| 몸통이 앞으로 숙여짐 | 굿모닝의 정상 힌지 / 프레스에서 동작 대체 후보 |
| 무릎이 골반 중앙선에 가까워짐 | 크로스 런지 문맥에서는 정상일 수 있음 / 지지발 기준 무릎 궤적 이탈 후보 |
| 어깨가 위로 움직임 | 프레스 상단의 정상 동작 가능 / 고정해야 할 동작에서 동반 이탈 후보 |
| 고개가 화면 아래로 향함 | 엎드린 운동의 기본 자세 가능 / 서서 하는 운동에서 고개 숙임 후보 |
| 다리 간격이 줄어듦 | 시저 크로스의 정상 교차 / 지지해야 하는 스쿼트의 발 배치 변화 후보 |

따라서 모든 종목에 `팔 벌림→팔을 붙이세요`, `몸통 숙임→펴세요`, `어깨 상승→내리세요`를 공통 적용하지 않는다. 관측 사실은 공통으로 계산하되 교정의 의미는 종목·단계·의도에 조건부로 둔다.

## 4. 출시 단위

한 종목이 출시됐다는 표식 하나로 모든 관절 지적을 켜지 않는다. 아래를 이벤트별로 기록한다.

```text
exercise / event / side / phase / view / model / dataVersion
meaningVerified / landmarkFidelity / directionLabels / temporalLabels
normalCounterexamples / outOfViewBehavior / repeatPrecisionRecall
cuePrecision / directionalConfusion / coverage / latency / releaseTier
```

예를 들어 스쿼트는 ‘반복 관측 가능, 정면 무릎 궤적 안내 가능, 깊이 미확인’일 수 있다. 이때 깊이까지 정상으로 표시하지 않는다. 크런치/Y 레이즈는 반복·움직임 범위가 동작하더라도 견갑골/경추의 자세 교정이 완성됐다고 부르지 않는다.

전 종목의 오류 완전성을 주장하기보다 다음 감사표를 채운다: `설명 가능한 정상 동작`, `정의된 방향 오류`, `확인된 비운동 행동`, `관측 불가`, `미분류`. 미분류 사건은 자가 라벨/검토로 새 이벤트 후보가 될 수 있지만, 정상의 반대라는 이유만으로 교정 명령으로 승격하지 않는다.
