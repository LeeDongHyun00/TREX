## 적용 규칙

‘제안 촬영 방향’은 그 방향에서 모든 항목을 검사한다는 의미가 아니다. `운동×변형×측×단계×실제 촬영 방향×항목`이 최소 지원 단위다. 여러 방향의 별도 세트를 합쳐 한 번에 전신을 판정한 것처럼 보고하지 않는다.

초기 개발 우선순위는 스쿼트/데드리프트의 의미 불일치, 푸시업 거리 붕괴, 교대 컬, 크런치 머리 움직임, 레이즈 운동면, 시저크로스 ID 교환이다. 준비 자세가 불명인 동작은 정규 반복으로 세지 않되 직접 기록 경로를 제공한다. 범위 목표는 사용자가 선택한 수행 목표이며 건강·안전 인증이 아니다.

26개 canonical ID와 별칭 매핑을 카탈로그·루틴·대체 운동·저장 계획 해석에 공통 적용한다. `기본 스쿼트`는 검색 별칭으로 바벨 스쿼트 계열에 연결하되 장비·변형 확인 없이 서로 같은 수행이라고 확정하지 않는다. 고블릿 스쿼트·버피 등 추가 운동을 이 표의 교정 대안으로 노출하지 않는다.
