# 목록·설정 UX 수정 — §43

2026-09-11. 사용자의 새 요청이 §42의 하단 전용 조작 원칙보다 우선한다. 항목 바로 옆에서 편집·비교 전환을 할 수 있게 하고, 설정은 익숙한 목록으로 복구한다.

## 반영 범위

- 운동·식단 하단의 더 보기 메뉴를 제거했다. 뒤로가기는 기능 버튼을 기본 탭 내비게이션으로 한 번에 되돌린다. 운동 기록은 운동 하단과 설정 목록에서 연다. 설정 탭에서는 기본 내비게이션을 유지한다.
- 설정은 프로필·운동 기록·화면 모드·알림·카메라 권한·도움말·버전·로그아웃으로 묶었다. 프로필 편집은 저장 시 기존 프로필을 복사해 입력 항목만 바꾼다. 알림/권한은 Android의 해당 앱 설정에 연결한다.
- 운동 기록은 최근 7일의 운동한 날/시간만 간결하게 요약한다. 요일·날짜를 고정 크기 상자에서 꺼냈고 모든 날짜는 처음에 닫혀 있다. 행을 누르면 한 날짜의 기록이 펼쳐지며 화살표가 회전한다. 확대/축소 220~250ms와 짧은 페이드를 함께 쓴다. 상세의 관측·자가 라벨은 보존한다. 정자세 평균 점수를 요약에 만들지 않는다.
- 운동 목록은 둥근 외곽과 얇은 내부 구분선으로 묶는다. 행 오른쪽 중앙의 수정 버튼은 해당 항목만 편집한다. 사용자가 선택한 흐름은 **설정 먼저 → 종목 변경에서 추천/카테고리**다. 이름 옆 비교 스위치는 바로 저장한다. 미지원 종목은 비활성화와 이유 표시를 유지한다.
- 길게 누른 뒤 위아래 이동하면 행이 살짝 커지고 떠오르며 다른 행이 자리를 옮긴다. 화면 가장자리에서는 자동 스크롤한다. 놓을 때 ID 기준 순서를 저장하고 제스처 취소 시 원래 순서를 복구한다. 화면 읽기 사용자에게 위/아래 이동·삭제 동작도 제공한다.
- 왼쪽 스와이프는 오른쪽 쓰레기통을 드러내고 임계 이동 후 삭제 확인을 연다. 확인 전에는 저장 계획을 바꾸지 않는다. 취소하면 행이 제자리로 돌아오고, 삭제하면 해당 ID만 제거한다. 운동 기록은 삭제하지 않는다.
- 종목 변경은 같은 주 사용 부위의 카탈로그 운동 최대 3개를 먼저 보여 준다. 카테고리는 접혀 있다가 누르면 포함 종목을 펼친다. 현재 종목은 대체 후보에서 제외하고 검색도 제공한다. 부위가 같다는 이유로 장비·난이도·개인 적합성이 검증됐다고 표현하지 않는다.
- 오른쪽 위 +에서 추가한 본운동은 **끝의 정리/회복 운동 묶음 앞**에 넣는다. 정리 운동이 없으면 맨 뒤, 새 회복 운동도 맨 뒤다. 기존 상대 순서는 보존한다. 선택 뒤 횟수·시간·세트·휴식을 설정하고 추가한다.
- 식단 오른쪽 위 수정 버튼은 영양 목표 편집을 연다. 과한 설명과 중첩 카드를 줄이고 저장/취소를 제공한다. 저장 전 초안은 실제 목표에 반영하지 않는다.

## 구현 위치

`WorkoutListScreen.kt`는 행 제스처/목록, `WorkoutEditor.kt`는 단일 항목 초안, `WorkoutCatalogUi.kt`는 부위 추천/분류와 추가·이동 정책, `SettingsScreen.kt`는 설정 화면이다. 기존 `RecordScreen.kt`, `MainScreens.kt`, `TrexApp.kt`, `Sheets.kt`의 진입/표시를 연결했다. 자세 평가 임계값·카운터·목표 진행 조건은 변경하지 않았다.
