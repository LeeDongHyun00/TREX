## 한눈에 보기

| 날 | 묶음 | 종목 수 | 필요한 것 | 예상 시간 |
|---|---|---|---|---|
| **1일차** | 🔵 바벨 | 5 | 바벨(가벼운 무게) | 약 55분 |
| **2일차** | 🟢 바닥 | 7 | 매트 | 약 45분 |
| **3일차** | 🔵 덤벨 + 🟢 서서 맨몸 | 3 + 4 | 덤벨 한 쌍 | 약 55분 |

**서서 하는 맨몸 4종목**(사이드 런지 · 크로스 런지 · 스탠딩 니업 · 스탠딩 사이드 크런치)은 따로 묶을 기구가 없어서 **덤벨 날에 붙였다**. 덤벨 3종목은 모두 어깨 운동이라, 사이에 하체·코어를 끼우면 어깨가 쉰다.

**날 순서의 이유**
- **1일차 바벨** — 바벨 컬·바벨 런지는 컴퓨터 검증까지 끝나 폰 검증만 남은 파일럿이다. 가장 먼저 결과를 볼 수 있다.
- **2일차 바닥** — 1일차에 런지·데드리프트·굿모닝으로 쓴 하체를 쉬게 한다.
- **3일차 덤벨 + 서서 맨몸** — 하체(사이드·크로스 런지)가 하루 쉰 뒤에 온다.

## 공통 규칙 (모든 날)

1. **같은 촬영 방향끼리 연달아 한다.** 하루 안의 순서는 폰을 덜 옮기게 짰다. 방향이 바뀌는 곳에 📱 표시를 했다.
2. **첫 세트는 항상 정상 자세다.** 본인 기준 검사는 처음 몇 회를 기준으로 삼는다. 처음부터 틀린 자세면 그게 '정상'이 된다.
3. **블록 사이·세트 끝에서 1~2초 멈춘다.** 카운터는 다음 하강이 와야 앞 회를 확정해서, 세트의 마지막 회를 구조적으로 놓친다.
4. **실제로 한 횟수를 세트마다 메모한다.** 앱이 센 수와 대조할 정답이다. 메모 양식은 맨 아래에 있다.
5. **런지류의 1회 = 왼쪽 한 번 + 오른쪽 한 번**이다(목표 10회 = 20걸음). 바벨 런지는 쪽별로 따로 센다.
6. **의도적인 오류 동작은 가벼운 무게로만 한다.** 특히 데드리프트·굿모닝에서 허리를 일부러 말지 않는다. 앱이 어차피 그 오류를 못 본다(척추 중립 규칙이 exclude).
7. **매일 끝나면 로그를 회수한다.** `python research/aihub_fitness/pull_logs.py` (adb 경로가 Windows 로 하드코딩돼 있어 확인이 필요하다)

세트 종류:
- **정상** — 바른 자세로 한다. 횟수 확인과 오탐 확인용.
- **지정 오류** — 블록 순서대로 정해진 오류를 섞는다. 파일럿 종목은 바로 채점표(`family_scorecard.py`)에 들어간다.
- **선택 오류** — 아직 채점 블록이 정의되지 않은 종목이다. 메모만 남겨 두면 다음 계열 작업의 재료가 된다.

## 1일차 — 🔵 바벨 (5종목)

| 순서 | 종목 | 방향 | 세트 | 등급 | 이번에 확인할 것 |
|---|---|---|---|---|---|
| 📱 | *폰: 왼쪽 앞(왼어깨가 폰에 가깝게 45°)* | | | | |
| 1 | **바벨 컬** | 왼쪽 앞 | 정상 10회 · 지정 오류 ×2 | A 파일럿 | 컬 검사 검출률 ≥ 80 %, 정상 블록 오탐 없음, 횟수 ±1 |
| 2 | **바벨 런지** | 왼쪽 앞 | 정상 10회 · 지정 오류 ×2 | A 파일럿 | 걸음 검사 검출률, 쪽별 카운트 |
| 📱 | *폰: 정면* | | | | |
| 3 | **업라이트로우** | 정면 | 정상 12회 ×2 · 선택 오류 1 | A | 횟수(`forearm_vert_mean`), ship '팔꿈치가 손목 리드' 오탐 |
| 4 | **바벨 데드리프트** | 정면 | 정상 10회 ×2 | B | 횟수(`hip_mean`), ship 2개 오탐 |
| 5 | **굿모닝** | 정면 | 정상 12회 ×2 | B | 횟수(`hip_mean`), ship 3개 오탐 |

**지정 오류 세트 (그대로 `--protocol` CSV 로 쓴다)**

```
exercise,order,blocks
바벨 컬,2,정상:5 팔꿈치앞:3 정상:2
바벨 컬,3,정상:4 숙임:3 팔꿈치벌림:3
바벨 런지,2,정상:4 얕게:3 숙임:3
바벨 런지,3,정상:4 무릎쏠림:3 어깨기울임:3
```

- `order` 는 그날 그 종목의 몇 번째 세트인지다. 1번째가 정상 세트라 오류 세트는 2·3번째다.
- 블록 뜻 — 컬: `팔꿈치앞` 팔꿈치를 앞으로 내밀기, `팔꿈치벌림` 옆으로 벌리기, `숙임` 상체 숙이기·반동. 런지: `얕게` 앞무릎 덜 굽히기, `숙임` 상체 숙이기, `무릎쏠림` 앞무릎 안쪽으로, `어깨기울임` 어깨 한쪽 내리기.
- 런지 블록의 숫자는 **걸음 수**다.

**업라이트로우 선택 오류**: `정상:6 손목먼저:4` — 팔꿈치보다 손목이 먼저 올라오게 한다.

**당일 채점**
```
python research/external_rep_replay/family_scorecard.py --exercise "바벨 컬" --phone <로그 폴더> --protocol day1.csv --since 2026-10-0X
python research/external_rep_replay/family_scorecard.py --exercise "바벨 런지" --phone <로그 폴더> --protocol day1.csv --since 2026-10-0X
```

## 2일차 — 🟢 바닥 (7종목)

바닥 규칙은 **전부 beta** 라 화면에 '참고'로만 나온다. 이날의 핵심은 **횟수가 맞는지**와 **정상 자세에서 참고 경고가 얼마나 뜨는지**다.

| 순서 | 종목 | 방향 | 세트 | 등급 | 이번에 확인할 것 |
|---|---|---|---|---|---|
| 📱 | *폰: 낮은 측면(몸 옆면이 보이게, 폰은 바닥 가까이)* | | | | |
| 1 | **푸쉬업** | 낮은 측면 | 정상 12회 · 선택 오류 1 | A 후보 | 횟수(검증된 신호), '얕았어요' 안내 |
| 2 | **니 푸쉬업** | 낮은 측면 | 정상 10회 · 선택 오류 1 | A 후보 | 위와 같음 |
| 3 | **플랭크** | 낮은 측면 | 정상 45초 · 선택 오류 1 | A 후보 | 직접 정렬 경고, 시간 측정 |
| 4 | **크런치** | 낮은 측면 | 정상 15회 ×2 | C | 횟수(`head_ground`), '덜 올라왔어요' 안내 |
| 5 | **레그 레이즈** | 낮은 측면 | 정상 12회 ×2 | C | 횟수(`hip_ang`) |
| 📱 | *폰: 앞쪽 사선(양팔·양다리가 겹치지 않게 몸을 비스듬히)* | | | | |
| 6 | **시저 크로스** | 앞쪽 사선 | 정상 20회 ×2 | C | 횟수(`knee_gap2d`) — 1회의 단위가 앱과 맞는지 |
| 7 | **Y 레이즈** | 앞쪽 사선 | 정상 12회 ×2 | C | 횟수(`hand_shoulder_off`) |

**선택 오류 세트**
- 푸쉬업·니 푸쉬업: `정상:6 얕게:3 고개숙임:3` — 가슴을 덜 내리기, 고개 떨구기
- 플랭크: `정상 20초 → 엉덩이 처짐 10초 → 엉덩이 들림 10초`

푸쉬업 계열을 앞에 둔 이유: A 후보라 지칠 때보다 기운 있을 때 깨끗한 정상 세트를 얻는 게 중요하다.

## 세트 메모 양식

세트가 끝날 때마다 한 줄씩 적는다. 시각은 대략이면 된다(로그와 맞출 때 쓴다).

```
day,time,exercise,order,type,blocks,actual_reps,app_reps,note
1,14:05,바벨 컬,1,정상,정상:10,10,9,마지막 회 멈춤 없이 끝냄
1,14:08,바벨 컬,2,지정,정상:5 팔꿈치앞:3 정상:2,10,10,
```

- `type`: 정상 / 지정 / 선택
- `app_reps`: 세트 끝 화면에 나온 수. 스탠딩 사이드 크런치는 빈칸.
