## 1. 페이지별 내용

### P1. 운동 기록(달력) — `RootRoute.Record` 고침 (G1·G3·G9)

프로토타입: 『G1·G3 기록(달력)』. 기존 `RecordScreen.kt`('최근 7일')를 대체한다.

| 구역 | 들어가는 것 | 데이터 |
|---|---|---|
| 머리 | "운동 기록" / 월 이름, ◀ ▶ 달 이동 | — |
| 달력 | 7열 격자. 운동한 날 진한 점, 목표 요일이 아닌 날 연한 점, 오늘 테두리, 선택 날 어두운 배경. 보관 기간 밖 달은 비활성 + "보관 기간 밖이에요" | `HistoryStore.month(yyyyMM)`, `UserProfile.dayMask`, `RetentionPolicy` |
| 연속·주간 카드(어두운 카드) | 연속 N일 · 최장 · 이번 주 n/N | `Streak` |
| 날짜 카드 | 선택 날의 종목 행: 이름 · 자세 교정/기록 전용 칩 · "60 kg × 10 · 10 · 8" · 자세 문장("무릎 안쪽 모임 2회 뺌") · PR 칩 · 메모 수 · RPE. 행 탭 → P4. 아래 '+ 기록 추가 · 수정' → P2 | `WorkoutHistoryItem.sets/note/postureCorrection` |
| 주간 요약 카드 | 운동일·세트 / 볼륨(+'추정 n세트') / 부위 비중 띠 + 범례 + "제품용 분류" 안내 | `WeeklySummary` |
| 월간 요약(달력 아래 접힘) | 운동일 · 세트 · 볼륨 · 가장 많이 한 종목 3 | `MonthlySummary` |

상태: **빈 달**("이 달엔 기록이 없어요") / **보관 밖** / **동기화 중**(상단 얇은 바, 기존 '마지막 동기화' 표기 재사용). 자세 점수 추이는 넣지 않는다(원칙 #1).

### P2. 기록 추가·수정 시트 — `MainSheet.ManualRecord` (G9)

프로토타입: 『G1·G3 기록(달력)』의 시트.

- 날짜(기본 = 선택 날, 미래 금지) · 종목 선택(→ P8 `Browse` 모드로 갔다 돌아옴) · 세트 행(kg·회·RPE·완료) `SetRowList` 공용 컴포넌트 · 메모 · 저장 / 삭제(수정일 때).
- 머리 문장 고정: "카메라·타이머 없이 적는 기록이에요. 자세 판정은 남지 않아요."
- 저장 → `WorkoutHistoryItem(source = "manual")`, PR 검사(§3.3) → PR 이면 저장 뒤 토스트 "개인 기록 갱신". XP +20(그날 첫 기록일 때).
- 수정 가능 범위: `source` 가 `manual`·`timer` 인 항목은 전부, `session`(카메라) 항목은 **세트의 kg·RPE·메모만**(횟수는 자가 라벨 경로 유지 — 판정과 횟수의 출처를 섞지 않는다).

### P3. 세트 입력 행 — 휴식·타이머 화면 고침 (G2)

프로토타입: 『G2 세트 입력』.

- `SessionScreens.kt` 휴식 화면(`TransitionSession`)의 링 아래에: **지난 세션 카드**("지난번 (11월 3일) 55 kg × 10 · 10 · 10 · RPE 8" + '그대로 채우기' — 빈 칸만 채움) → `SetRowList`(현재 세트까지 활성) → RPE 칩 → 메모.
- 카메라 세션: '회' 칸에 자동 카운트(`countedReps`)가 미리 들어오고 보조 문장 "카메라가 센 값이에요. 다르면 고쳐 주세요". 고치면 `reps`(확정).
- `TimerSessionScreen` 의 '횟수 기록' 버튼 → 같은 `SetRowList` 가 펼쳐진다.
- 상태는 `SetInputState` 홀더(`LiveSessionRefs` 옆) — `PostureLiveSessionScreen` 지역 변수 금지.
- 완료 화면으로 넘길 때 `sets` 를 채워 `WorkoutHistoryItem` 을 만든다. `reps: String` 요약은 `sets` 에서 생성.

### P4. 종목 상세 — `RootRoute.ExerciseDetail(exerciseId)` 새 페이지 (G3)

프로토타입: 『G3 종목 상세』.

| 구역 | 내용 |
|---|---|
| 머리 | 부위 · 기구 / 이름 + 칩(자세 교정 지원 / 기록 전용 / 직접 추가) |
| 숫자 카드 2 | 무게 종목: 최고 무게(날짜·횟수) · 추정 1RM("60 kg × 10 (Epley)"). 맨몸: 최고 횟수 · 누적 횟수. 시간: 최장 유지 · 누적 시간 |
| 추이 차트 | 최근 8세션 최고 무게(또는 횟수·시간) 꺾은선, PR 점 강조. 세션 2개 미만이면 "두 번 이상 기록하면 추이가 보여요" |

### P5. 완료 화면 보상 띠 — `RootRoute.Complete` 고침 (G5)

프로토타입: 『G5 완료 + 보상』. 기존 완료 화면 **위에 한 블록**만 더한다.

- 띠 내용(있는 것만): PR 갱신(종목·새 기록·이전 기록·🏆) / +XP · 다음 레벨까지 / 🔥 연속 N일 / 새 배지 카드(제목·아이콘).
- 없으면 띠는 "오늘도 해냈어룡 · +50 XP" 한 줄.
- 기록 카드에 **볼륨** 칸 추가. 자세 블록·자가 라벨·오운완 버튼은 그대로. '업적 보기' → P6.
- 오운완 카드 이미지에는 XP·배지·PR 을 넣지 않는다.

### P6. 업적 — `RootRoute.Achievements` 새 페이지 (G5)

프로토타입: 『G5 업적·연속』.

- 레벨 카드(어두운 카드): Lv · 다음 레벨까지 XP · 진행 바 · 문장 "XP 는 운동을 마치고 기록할 때만 쌓여요. 자세 점수는 XP 와 무관해요."
- 연속 카드 2: 현재·최장 / 이번 주 요일 점.
- 배지 격자 3열(획득 = 라임 원, 미획득 = 흐림). 배지 탭 → 작은 시트(조건·획득일·진행 "32 / 50").
- XP 내역(접힘 목록): 날짜 · 사유 · +XP, 최근 30건.
- 진입: 설정(내 정보) 새 행 '업적', P5, 홈 연속 카드.

### P7. 체중·신체 기록 — `RootRoute.Body` 새 페이지 (G3)

- 최신 체중 큰 숫자 · 변화(7일·30일) · 꺾은선(90일) · 항목 목록(날짜·kg·체지방%·메모) · '+ 오늘 기록' 시트(kg 숫자 휠 0.1 단위, 체지방 선택).
- 저장 → `body` 키, 프로필 `weightKg` 갱신 → 영양 목표 재계산(`WorkoutMath`)·근육 부하 체격 계수.
- 진입: 설정 '체중 기록', 프로필 편집의 체중 칸 옆 '기록 ▸'. Health Connect 읽기(2차)는 같은 목록에 출처 칩 '연동'.

### P9. 종목 직접 추가 시트 — `MainSheet.CustomWorkout` (G4)

- 이름(필수, 1~30자, 기존 이름과 중복 경고) · 부위(필수) · 기구(필수) · 주 근육(선택, 18개 중) · 단위(횟수/시간).
- 머리 문장: "내 기록에만 쓰여요. 자세 비교와 근육 부하 추정은 되지 않아요."(근육을 고르면 "고른 근육으로만 대략 추정해요").
- 저장 → `custom_workouts`(id `custom:<uuid>`). 삭제는 기록이 있으면 '숨김' 으로(이력 보존).

### P10. 추천 루틴 — 운동 탭 세그먼트 '추천' (G6)

프로토타입: 『G6 추천 루틴·요일』. 운동 탭 머리에 세그먼트 **내 루틴 · 추천 · 받은 루틴**(받은 루틴은 기존 공유 링크 수신함).

- 필터 칩 줄: 목표 · 장소 · 주 N일 · 장비 — 온보딩 답으로 미리 켜짐, 바꾸면 프로필에 저장.
- '오늘의 제안' 한 줄 카드(피로도·날씨 — 둘 다 없으면 카드 없음) + '적용'.
- 프리셋 카드 목록: 이름 · 분할 · "6종목 · 자세 교정 5" · 예상 시간 · 배정 요일 칩. 버튼 '미리 보기'(→ P12) / '요일에 넣기'(요일 선택 작은 시트 → P11) / 오늘 슬롯이 비었으면 '오늘 루틴으로'.
- 바닥 안내: "팀이 쓴 분할 템플릿이에요. 자세 교정 지원 종목을 앞에 둡니다."

### P11. 주간 루틴(요일 줄) — 운동 탭 '내 루틴' 머리 고침 (G6)

프로토타입: 『G6 요일 루틴』.

- `RoutineHero` 위에 요일 7칸(오늘 기본). 칸 탭 → 그 요일 루틴 목록(기존 `WorkoutListScreen` 행·드래그·스와이프·자세 토글·수정 그대로).
- 빈 요일: "휴식 · 루틴 넣기"(→ P10 또는 보관함에서 고르기).
- 기존 '오늘 루틴'(`plan`)은 '매일' 칸(요일 줄 맨 앞 '매일' 토글)으로 이관. 홈 '오늘 운동' 과 '운동 시작' 은 오늘 요일 → 없으면 '매일'.

- 이름 · 부위 비중 띠 · 예상 시간 · 종목 목록(칩: 자세 교정/기록 전용, 세트×목표) · 버튼 '오늘 루틴으로' / '요일에 넣기' / '보관함에 저장'. 받은 루틴(`SharedRoutine`)도 같은 시트를 쓴다(지금의 수신 화면과 합침).

### P13. 설정 — 행 추가 (G1·G7·G8·G10)

`SettingsScreen` 에 그룹 둘을 더한다(기존 행 순서는 유지).

| 그룹 | 행 | 동작 |
|---|---|---|
| 기록 | 운동 기록 | (기존) → P1 |
| | 업적 | → P6 |
| | 체중 기록 | → P7 |
| | 기록 보관 기간 · "제한 없음" | → P14 |
| | 기록 내보내기 | → P15 |
| | 운동 기록 전체 삭제(빨강) | 확인 2단계(문장 입력 없이 두 번 확인) → 로컬·백업 삭제 |
| 알림 | 알림 · "운동 요일 · 휴식 끝" | → P16 (지금 시스템 설정으로 가는 행을 대체, 시스템 설정 링크는 P16 안에) |
| 연동(2차) | Health Connect / 건강 | 토글 + 권한 요청. 미구현 동안은 행을 숨긴다(비활성 행을 보이지 않는다) |

### P14. 기록 보관 기간 시트 (G1)

- 라디오 7일 / 90일 / 1년 / 제한 없음(추천). 현재 값 표시. 줄일 때 경고 "그 밖의 기록이 이 기기와 백업에서 지워져요. 지우기 전에 내보내기를 권해요" + '내보내기' 바로가기 + '그래도 바꾸기'.
- 저장 → `settings_records.retentionDays`(동기화), `RetentionPolicy` 즉시 적용.

### P15. 내보내기 시트 (G10)

- 형식 CSV / JSON · 기간(전체 / 올해 / 최근 90일) · 포함 항목(운동 · 체중 · 식단) → '내보내기' → 공유 시트. 완료 토스트.

### P16. 알림 설정 시트 (G7)

- 권한 상태 줄(없으면 '허용하기' → 시스템 권한, 거부 상태면 시스템 설정 링크).
- 토글 3: 운동 요일 알림(시각 선택, 요일은 `dayMask`) / 휴식 끝(화면 꺼짐 때) / 개인 기록·연속(PR, 끊기기 전날 20:00).
- 커뮤니티 알림 행: "없음"(1차 비목표) 회색.

### P17. 물 기록 — 식단 탭 카드 (G11)

- 영양 요약 아래 카드: 오늘 n / 목표 2.0 L, 컵(250 ml) +/− 버튼, 7칸 미니 바. 기존 `addWater`·`waterByDay`·동기화 키 `water` 를 그대로 쓴다. 새 모델 없음.

### P18. 홈 카드 갱신 (G3·G5·G6)

- '운동한 날' 7일 점 줄 → 탭하면 P1. 연속 카드 → 7일 상한 해제, 탭하면 P6.
- '오늘 운동' 카드 → 오늘 요일 슬롯(P11). 비어 있으면 "오늘은 휴식 · 추천 루틴 보기"(→ P10).
- 스탯 카드 '운동 소모 · 추정' 옆에 '이번 주 볼륨'(주간 요약과 같은 값).
