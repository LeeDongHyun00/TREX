## 검증과 제한

- 문서의 로컬 링크와 차이를 검사했다. 앱 코드·Gradle·규칙·모델은 이번 협업 준비에서 변경하지 않았다.
- 첫 push는 조상 이력의 118.34 MB 파일로 거절됐다. 동일 코드의 원격 기준 위에 문서만 옮겼으며 기존 로컬 이력은 `codex/ios-kmp-local-history-20260912`에 보존했다. 공유 이력에는 이 로컬 보존 브랜치를 merge하지 않는다.
- 현재 세션에서는 앱 유닛 테스트/빌드/성능 계측/기기 설치를 실행하지 않았다. 과거 테스트 건수를 이번 검사 결과로 사용하지 않는다.
- 실제 공통 API 계약 커밋: **없음**. 설계의 API는 의사 인터페이스다.
- Mac 환경·수신은 `6a569ec`로 확인했다. Intel/Xcode 16.2이며 Native 빌드·iPhone 실행은 미검증이다.
- Windows Python 3.13.12에서 자산 검사 기본 모드 종료 0: 내용 8개 일치, 규칙 배열 분포 일치. `--strict-bytes` 종료 1: 모델은 동일하고 텍스트 7개는 CRLF 차이. 앱 번들 해시 일치나 플랫폼 동등성 결과가 아니다.
- 별도 임시 폴더에서 Git 기준 바이트 8개를 추출한 strict 검사는 종료 0, 텍스트 내용 변경/파일 누락은 각각 종료 1로 검출했다. 실제 자산 원본은 수정하지 않았다. 이 검사는 Windows 실행이며 Mac 도구 실행을 대신하지 않는다.

## 다음 작업과 소유 영역

- 다음 Windows 범위는 P0 기준 테스트/이벤트 재생·성능 계측 계획의 구체화와 P1 계산 모듈 추출이다.
- `app/`, 공통 코드/테스트, 루트 Gradle, 버전 카탈로그, 정본 자산·설계 연결 문서를 담당한다.
- Mac에는 M0 실제 컴파일/기기 실행 결과가 다음 입력이다. M1/M2는 독립 진행하며 P1 Native 타깃은 기본 arm64 + 선택 Intel 검증 타깃으로 준비한다. Kotlin/AGP 하향은 이번 결정에 포함하지 않는다.
- 공통 모듈이 빌드되는 커밋을 push한 뒤, 그 SHA와 실제 공개 API/검증 범위를 이 파일에 갱신한다.
