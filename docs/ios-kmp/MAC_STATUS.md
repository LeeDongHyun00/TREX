# Mac 작업 상태

**이 파일은 Windows에서 협업 시작용으로 만든 양식이다. Mac에서 검사하거나 수신한 결과가 아니다. 이후 Mac 담당이 갱신한다.**

- **갱신일:** 2026-09-12 — 양식 생성일
- **담당:** Mac Codex, 아직 실행/수신 미확인
- **작업 브랜치:** `codex/ios-kmp-mac`
- **통합 브랜치:** `codex/ios-posture-kmp`
- **제안 기준 소스:** `5c7118e` 및 통합 브랜치의 설계 커밋
- **실제로 가져온 통합 커밋:** 미확인
- **현재 단계:** 첫 환경 검사 대기

## 첫 작업

[협업 규약](../IOS_KMP_COLLABORATION.md)의 읽기 순서와 역할을 따른다. 환경 검사·설계 검토 후 실제 실행 명령/결과, 가져온 커밋, 설치가 필요한 도구, 다음 단계의 장애를 이 파일에 기록한다. 현재 없는 테스트나 iPhone 검증을 통과한 것으로 쓰지 않는다.

## Windows에 필요한 입력

검토 전. 환경 확인 후 공통 코드/빌드에 필요한 제약을 기록한다. iOS 구현은 Windows의 P1 API 커밋을 받은 뒤 이어간다.
