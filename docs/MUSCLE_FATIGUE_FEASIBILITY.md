# 근육 사용·피로·회복 표시 가능성 조사

조사일: 2026-09-28. 대상: 현재 로컬 TREX 코드와 3D 근육 모형.
**연구와 설계 판단만 수행했다. 피로 계산·기록 구조·Android 화면은 구현하지 않았다.**

후속 결정: 사용자가 세션 기반 추정치로 개발할 방향을 선택했다. 현재 입력으로 시작하는 수식·기본값·기록 구조·3D 연동 설계는 [세션 피로 설계](MUSCLE_SESSION_FATIGUE_DESIGN.md)를 따른다. 아래의 실제 생리학적 측정에 관한 한계는 유지하되, 입력이 적다는 이유로 간편 추정 기능 자체를 보류하는 정책은 아니다.

## 1. 결론

운동 종목과 수행 기록으로 **일반적으로 참여하는 근육군**과 **기록된 운동 노출량**을 표시하는 것은 가능하다. 현재의 횟수·세트·자세 점수·키·몸무게만으로 개인의 각 근육이 실제로 얼마나 피로한지, 몇 % 회복됐는지를 식별할 수는 없다. 이는 입력 정보의 한계이며 3D 표현을 정교하게 만드는 것으로 해결되지 않는다.

추가 정보를 수집하고 개인별·종목별 검증을 하면 **운동 부하 및 회복 상태의 추정치**를 개발할 수 있다. 이를 측정된 근피로도나 부상 위험 확률로 표현하면 안 된다. 근육 활성, 힘, 일량, 피로, 근육통, 근손상은 서로 다른 양이다. 문헌의 EMG 상대값을 그대로 피로 비율이나 근육별 분배율로 바꾸는 근거는 이번 조사에서 확보하지 못했다.

| 표시하려는 것 | 현재 가능한 범위 |
|---|---|
| 어떤 근육을 사용하는 운동인가 | 운동 변형·자세에 맞춘 주동/보조/안정화 근육의 문헌 기반 안내 |
| 기록상 그 부위를 얼마나 운동했나 | 관측/수동/목표 횟수 구분 후 세트·반복·시간 등 원자료 표시 |
| 실제 개인의 근육별 힘·활성 | 현재 요약 기록으로 식별 불가; 별도 생체역학 추정도 검증 필요 |
| 실제 피로 63%, 회복 82% | 현재 근거로 제공 불가 |
| 최근 운동 부하·회복 추정 범주 | 추가 입력·개인 보정·오차 검증 후 후보 기능 |

### 누적 회복 계산 전 해결해야 하는 기록 문제

1. `TrexAppState.recordCompletedSession()`이 `replaceTodayWith()`를 호출하며, `TrexData.kt`의 이 함수는 같은 날짜 기록을 교체한다. 하루 여러 독립 세션의 누적 운동량을 보존하는 원장으로 그대로 쓰기 어렵다.
2. `RecordRetention.kt`와 앱 상태 갱신은 최근 **7일** 사용자 기록을 유지한다. 장기 개인화용 학습 기록이 따로 필요하다. 연구용 JSONL과 사용자 기록의 저장 범위를 혼동하면 안 된다.
3. 세부 로그의 `repUnit`, `repSides`, `repArmCycles` 등이 사용자 기록의 `PostureCorrection`으로 모두 전달되지는 않는다. 런지의 좌우 1쌍과 편측 1회, 컬의 팔별 주기를 임의로 같은 단위로 더하면 안 된다.
4. `repValid`에는 가동범위 유보가 포함될 수 있다. 이를 모두 정확한 반복으로 취급하지 않는다. ABSTAIN은 안 한 운동도, 정상 운동도 아니다.

**자세 점수 × 반복 수를 ‘유효 운동량’으로 사용하는 방법은 채택하지 않는다.** 자세 점수가 낮아도 신체 부하는 발생하며, 다른 근육으로 이동한 부하량도 점수 하나로 복원할 수 없다. 관측 신뢰도와 운동 부하를 별도 축으로 보관해야 한다.

## 3. 연구 근거와 적용 한계

### 같은 반복 수라도 피로는 다르다

Morán-Navarro 등(2017)은 훈련된 남성 10명의 벤치프레스·스쿼트에서 실패까지 수행한 3×10과 총 반복 수가 같은 6×5를 비교했다. 실패 조건의 운동 직후 수행 저하가 더 크고 회복도 더 느렸다. 반복 수만으로 동일한 피로를 배정할 수 없다는 직접적인 근거다. 특정 조건의 집단 결과를 모든 사용자·근육의 고정 회복 시간으로 적용할 수는 없다. [원 논문 초록](https://pubmed.ncbi.nlm.nih.gov/28965198/)

Refalo 등(2023)은 훈련된 남녀 24명의 75% 1RM 벤치프레스 6세트에서 실패, 1회 여유, 3회 여유 조건을 비교했다. 4분 뒤 고정 중량의 속도 감소는 각각 약 25%, 13%, 8%였다. 노력도 차이가 중요하다는 근거이며, **이 숫자는 개별 근육의 피로 백분율이 아니다.** 스쿼트·런지·컬 모델의 고정 계수로 복사하지 않는다. [원 논문 초록·도표 설명](https://pubmed.ncbi.nlm.nih.gov/36752989/)

### 피로 모델은 입력과 보정이 필요하다

Xia와 Frey Law(2008)의 3구획 모델은 휴식·활성·피로 상태 사이의 이동과 피로/회복률을 모델링한다. 상대적인 근력 요구량 및 시간 경과를 알아야 하며, 키·몸무게만 넣으면 근육별 회복도가 나오는 공식이 아니다. 논문 초록의 등척성 검증 범위를 현재 앱의 동적 운동 후 장기 회복에 그대로 확장하지 않는다. [원 논문 초록](https://pubmed.ncbi.nlm.nih.gov/18789445/)

Looft 등(2018)은 간헐적 과제의 토크 저하를 예측하도록 휴식 중 회복을 수정한 모델을 제시했다. 쉬는 방식도 모델 선택에 영향을 준다는 근거다. 이번에는 공개 검색 초록 범위만 확인했으며, TREX의 개인 근육별 회복 예측을 검증한 연구로 취급하지 않는다. [원 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC6092960/)

### 키·체중과 카메라가 할 수 있는 일

OpenCap(Uhlrich 등, 2023)은 스마트폰 영상의 운동학 추정에 신체 크기 조정과 근골격 시뮬레이션을 결합해 역학량을 추정했다. 키·체중은 이런 모델의 보조 입력이지만, TREX의 자세 점수 요약은 그 계산을 대체하지 않는다. 힘 추정의 검증과 다음 날 피로·회복 예측의 검증도 별개다. 이 논문은 원래 다중 카메라 시스템이며 단일 카메라 접근이 원천적으로 불가능하다는 결론은 아니다. [PLOS 원문](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011462)

### 사용자 느낌도 완전한 정답은 아니다

RIR 연구(2023)는 실패에 가까운 시점 및 뒤쪽 세트에서 예측이 더 정확함을 보고했다. RIR은 유용하지만 오차가 있는 자기 보고다. 해당 연구에서 성별·훈련 경험 효과가 유의하지 않았으므로 초보자나 특정 성별의 응답을 일괄 무효화할 근거로 쓰지 않는다. [원 논문 초록](https://pubmed.ncbi.nlm.nih.gov/37036795/)

Nosaka 등(2002)은 지연성 근육통이 편심성 운동 후 근손상 크기를 잘 반영하지 않음을 보고했다. 통증·근육통을 회복 상태의 유일한 정답으로 사용할 수 없다. [원 논문 초록](https://pubmed.ncbi.nlm.nih.gov/12453160/)

## 4. 더 받아야 할 입력 — 향후 개발 후보

최소 입력은 다음과 같다. 아직 추가하지 않았다.

- 실제 사용 중량과 단위: 덤벨 한 손 기준인지 양손 합계인지, 맨몸/보조/외부 부하 구분.
- 실제 완료 세트·반복·좌우 단위: 자동/수동/계획값 출처, 유보·일부만 보인 반복도 구분.
- 세트 종료 노력도: ‘몇 회 더 할 수 있었나요?’라는 RIR 범주와 모름 옵션. 필요하면 RPE를 보조로 사용.
- 실제 세트 시작/종료·휴식·운동일 시각, 여러 세션과 다른 날 운동을 잃지 않는 누적 원장.
- 개인 능력 기준: 동일 운동·중량에서의 평소 수행, 훈련 이력. 초보자에게 최대중량 검사를 필수로 요구하지 않는다.
- 이후 회복 피드백: 같은 조건의 안전한 수행 확인, 주관적 준비도·근육통·수면을 각각 구분해서 수집.

예를 들어 같은 키·체중인 사람이 덤벨 컬을 10회 했더라도 2kg과 12kg은 다르다. 같은 중량이어도 평소 최대 수행능력과 남은 반복 여력이 다르면 피로가 다를 수 있다. 체중으로 근육량·개인 근력·중량을 대신 추정하지 않는다. 성별 모형 선택만으로 회복 속도를 고정하지 않는다.

## 5. 제품에 적용한다면 권하는 단계

1. **사용 근육 안내:** 현재 운동 변형에 맞춰 근육군을 연결한다. 문헌의 일반적 참여 관계임을 유지하고 사람마다 측정된 활성량으로 부르지 않는다.
2. **최근 운동 부하:** 검증 가능한 세트·반복·중량·시간을 먼저 보여준다. 색은 해당 부위의 기록된 노출 정도를 나타낸다. 다른 운동의 kg×반복을 생리학적으로 동등한 단위로 합산하지 않는다.
3. **회복 추정:** 추가 입력과 개인 이력이 충분할 때만 범주/범위로 시험한다. 임의의 48시간 선형·지수 감소식은 검증 전 가설로 명시한다.
4. **평가:** 운동 전후·24/48시간 등의 동일 조건 수행 지표를 수집하고, 횟수만 쓰는 기준 모델과 추가 입력 모델을 비교한다. 사람과 날짜를 분리한 검증, 오차·구간 포함률·불확실성·누락 데이터 성능을 보고한다. 근육 하나하나의 실제 회복이라고 주장하려면 그 해상도에 맞는 별도 생리학적 검증이 필요하다.

154개 독립 메시를 색칠할 수 있다는 것은 154개 근육의 피로를 독립적으로 알 수 있다는 뜻이 아니다. 초기에는 검증 가능한 근육군 수준이 적절하다. 기록이 없는 부위는 ‘정보 부족’으로 남기며 **100% 회복**으로 초기화하지 않는다. 0% 기본 근육색은 시각 계약으로 유지할 수 있지만 ‘측정된 피로 0%’라는 의미를 자동 부여하지 않는다.

## 6. 이번 작업 범위

모형의 기본 팔·손 자세만 수정했다. 피로 기능의 수식·DB·앱 UI·자세 엔진은 변경하지 않았다. 전문 의료인 검수나 실제 근피로 측정 실험을 수행한 결과가 아니라 공개 연구와 코드 구조에 대한 타당성 조사다.
