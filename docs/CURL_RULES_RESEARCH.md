## 1. 반동·팔꿈치 이탈

### 1.1 무엇이 판별하나 (B1, '팔꿈치 위치 고정' 위반 = 팔꿈치 내밀기, n 1,354/뷰)
| 후보 | GT 3D | MP 2D B(−33°) | MP 2D C(정면) | MP 2D D(+39°, 앱) | MP 월드 D |
|---|---|---|---|---|---|
| 현 규칙 `elbow_torso_R__mean` | .900 | .356 | .246 | .927 | **.906 (오탐 16 %·검출 82 %)** |
| **`elbow_torso_fwd` 양팔 평균, 세트 평균** | .945 | **.961** | — | **.958** | .902 |
| 같은 것, 수축 프레임 값 | .930 | .951 | — | .951 | .797 |
| 같은 것, 반복 안 변화(수축 − 이완) | .775 | .800 | — | .781 | .581 |
| 팔꿈치 이동 크기(사용자 안 ①) | .829 | .839 | .811 | .821 | .819 |
| 상완 앞 기울기 ° | .853 | .921 | — | .920 | .847 |
| 팔꿈치 간격 벌어짐(사용자 안 ①) | .419 | .374 | .402 | .337 | .393 |

- **앞 성분이 답이다.** 2D 사선에서 MediaPipe 손실이 거의 없다(같은 뷰 사람 주석 상한 .963~.966). 정면(C)은 앞 성분이 깊이 축이라 어떤 후보도 0.85 를 못 넘는다 → 정면에서는 유보.
- **세트 평균 ≥ 수축 프레임 값 > 반복 안 변화.** 성긴 프레임에서 "그 반복의 이완 프레임"을 빼면 잡음만 는다. 반복 단위로 판정하되 기준은 **세트 시작 자세(여러 프레임 중앙값)** 로 둔다(세션 중심화 AUC .983 이 그 근거).
- 현 규칙의 문제: 월드·먼 팔꿈치(R) 세트 평균 — D 에서 가까운 팔꿈치(L)는 편향 +0.068 로 정상의 86 % 가 걸리고, B 에서는 반대. 2D 양팔 평균은 뷰 등급으로 앞/뒤 부호만 정하면 B/D 모두 된다.
- 운영점(MP 2D D, 양팔 평균 세트 평균): 정상 중앙 0.017·p95 0.089, 위반 0.124 → **오탐 5 % 에 검출 0.79**(B 0.84).

### 1.2 정상 컬에서 팔꿈치는 얼마나 움직이나 (B2 MM-Fit 정면 정상 598회, 반복 안)
| 후보 | p50 | p95 | p99 | 사람별 p95 | 띠 → 정상 초과 |
|---|---|---|---|---|---|
| 상완 전방 스윙(월드 `upperarm_vert`) | 13° | 38° | 45° | **10~46°(4배)** | >30° 8 % · >40° 5 % · >50° 1 % |
| 팔꿈치–몸통 이탈(월드 `elbow_torso` 상승) | 0.10 | 0.21 | 0.24 | 0.18~0.27(고름) | >0.20 9 % · >0.25 1 % |
| 몸통 기울기 범위(월드 `torso_incl`) | 5° | 13° | 16° | — | >10° 11 % · >15° 1.3 % |
| 어깨 상승 | 0.006 | 0.025 | 0.043 | — | >0.03 2 % |

- 상완 스윙의 사람별 폭이 4배인 것은 정면 카메라의 깊이 오차일 가능성이 크다(B1: 월드 기울기 정면 세트 범위 p95 31°). **월드 기울기·월드 상완 각은 정면에서 못 쓴다** — 사선 2D 기울기 비(ρ 0.76~0.81, 잔차 2.5~2.8°)로 잰다.
- 문헌(B3): 반동의 관측 신호 = 어깨 굴곡(상완–몸통 각). 정상 ≈10°, 피로 ≈20°, 의도적 변형 30°, 검출 코드 35~40°. 몸통 젖힘의 크기를 잰 컬 연구는 없다.
- 폰 2세트(정답 없음): 컬이 아닌 구간(몸통 25~36° 숙임, 상완 91~115° 스윙)에서 앱이 2회를 셌고, 띠(상완 >30°, 이탈 >0.24)가 그 구간만 잡았다 — 정상 반복 초과 0.

### 1.3 팔꿈치 벌어짐
- AIHub 라벨은 반대 방향(내밀면 좁아짐). MM-Fit 정상 반복에서 3D 팔꿈치 간격은 수축 시 +0.11~0.23 어깨폭 **늘어난다**(전완이 돌며 자연스럽게). 2D 간격은 뷰에 따라 p95 0.14↔0.39 로 흔들려 띠로 못 쓴다. 문헌 수치 없음.
- → **베타 화면 참고**: 3D 팔꿈치 간격 ÷ 어깨폭 세트 최대 ≥ 1.8(정상 초과 3~4 %) 또는 시작 대비 +0.5(1~4 %). 사용자 라벨 세트(일부러 벌린 반복)로 검출률을 잰 뒤에 승격 여부.

## 2. 1회의 정의 — 가동 범위

### 2.1 척도 문제 (B1·B2)
| 신호 | 수축 최소각 vs 정답 | 진폭 vs 정답 |
|---|---|---|
| MediaPipe 월드 팔꿈치각(앱) | ρ 0.04~0.47, 편향 **+33~39°** | r **0.56~0.73** |
| 2D 이미지 팔꿈치각, 사선 D | ρ 0.55(사람 안 0.69), 편향 −12°, 잡음 7° | — |
| 2D 이미지 팔꿈치각, 정면 | ρ 0.17 | — |
| 손목 상승 ÷ 전완(2D) | — | ρ −0.05~−0.13(포화, 못 씀) |

- 정답(GT 3D) 정상 수축각 p5/50/95 = 40/55/71°, 이완 161/170/176°. 사람 간 SD 9.5° ≈ 사람 안 7.2° — 개인차가 크므로 개인화는 옳다. 그러나 최선 신호의 사람 안 잡음(7~10°)이 사람 안 진실 산포(8.3°)와 같아, **각 10° 차이는 어떤 신호로도 못 가른다.**
- 앱 ROM 81.3° 는 GT 척도(`REP_VALIDITY.md`)다. 월드 신호에 대면 정상 클립의 세트 최소각이 B 50 %·C 95 %·D 85 % 에서 81.3° 를 넘는다(GT 2 %). **기준 자체가 척도가 다르다** — "반쯤 들어도 1회" 이전의 문제.
- 월드 편향의 실체: 수축 시 월드 **상완 길이가 짧아진다**(B 19.7 vs 이완 24.3 cm) — 들어 올린 팔의 3D 복원 오류.

### 2.2 게이트 시뮬레이션 (B2, 정답 598회·11명, 분할 완벽 가정의 상한)
| 게이트 | 정답 반복 유지율 | 세트 정확 일치 | 사람별 최저 |
|---|---|---|---|
| 절대: 수축 ≤ 90° 이고 이완 ≥ 140° | 0.69 | 0.15 | 0.40 |
| 절대: ≤ 100° 이고 ≥ 130° | 0.92 | 0.65 | — |
| 비율: 진폭 ≥ 0.7 × 첫 3회 진폭(양팔 섞음) | 0.91 | 0.70 | 0.62(한 팔이 약한 사람) |
| **비율: 진폭 ≥ 0.7 × 같은 팔 첫 2회** | **0.94** | **0.80** | 0.78 |
| 깊이 ≥ 0.7 × 첫 3회 **이고** 복귀 ≥ 시작 −20° | 0.92 | 0.80 | — |

- 300 ms 는 30 fps 대비 최소각 +1.4°, 진폭 −3°(MAE 3~5°) — 샘플링이 아니라 MediaPipe 척도가 손실의 주원인.
- 세트 정확(0.80)이 유지율(0.94)보다 훨씬 낮은 것은 세트당 한 회만 걸려도 깨지기 때문 — '정확 M회' 표시는 이 크기의 오차를 갖는다.
- 문헌(B3): 부분 = 개인 전체 ROM 의 50 %, 국면 = 33/67 %, 임계 = 30/70 % 등 **개인 범위 대비 비율** 선례가 여럿. 고정 비율은 종목·개인마다 달라(덤벨 컬 실측 63 %, 46~88 %) 정의가 못 되고, 개인 기준선 위에서만 의미가 있다.

### 2.3 확정 — 1회
```

본인 기준 진폭 A0(팔별) : 그 팔 첫 2~3 사이클 진폭의 중앙값. 단 A0 ≥ 50°(MM-Fit 정상 p5 42~56°) — 미만이면 "기준 못 잡음", 사이클은 세되 ROM 은 유보

부분           : 진폭이 35° 이상이나 위 조건 미달 — 세지 않고 '부분 N회' 로 기록(COACH·TRACK 공통, 기록 모드도 본인 기준이므로 같다)
```

- 원칙 #3 과의 관계: 가동 범위의 위 끝은 사람마다 다르고(전완·이두 두께, B3) MediaPipe 척도가 사람·뷰별로 다르므로, COACH 도 모집단 절대 각이 아니라 **본인 기준 + 모집단 진폭 하한(45°)** 을 쓴다. 모집단은 하한(45~50°)에만 들어간다.
- 위험: 첫 2~3회를 일부러 짧게 하면 기준이 낮아진다 → 하한 50° 가 막는다. 첫 회가 비정상적으로 크면 이후가 다 '부분' 이 된다 → 기준은 중앙값, 세트 중 갱신하지 않는다(단순).

## 3. 교대 컬 — 팔별로 센다
- MM-Fit 컬은 59세트 전부 교대(위상차 0.50 ± 0.01). 현행 `elbow_mean` 은 두 팔 평균이라 한 반복에서 최소 114~116° 까지만 내려가고 재현율 0.09 — **못 센다**. 설계 §18.3 팔별 카운터 min(nL, nR): MediaPipe 교대 세트 정확 0.90, 3D 1.00, 합성 동시 컬 1.00.
- 폰 2세트는 동시 컬(위상차 0.00) → 지금 정의(사이클 = 1회)가 맞았다. 팔별 신호로 가면 둘 다 된다: 위상차 ≥ 0.35 주기면 교대, 아니면 동시(B2 분포가 0.0 과 0.5 로 깨끗이 갈림).
- **결정 필요(§4 ①)**: 교대 컬의 표시 단위 — "왼 + 오른 = 1회"(런지 결정과 같음, 문헌 관행 A) vs "팔당 1회"(관행 B). 로그는 팔별 사이클을 그대로 남긴다.

## 4. 반동·이탈 판정 — 확정안 (beta 로 시작, 입장 조건 통과 후 ship)
```
컬 아님(사이클 기각, 원칙 #7 '이 종목의 반복인가')  — 판별 게이트, 자세 검사 아님
   사이클 안 몸통 기울기 범위(2D 사선 기울기 비 ≥ 0.26 ≈ 21°, 정상 초과 0.6~1.2 %)  또는  상완 앞 기울기 ≥ 50°(정상 초과 1 %)
   → 이 사이클은 "컬이 아니에요 — 몸통을 세우고 팔꿈치를 옆구리에 붙이세요"

팔꿈치 앞 이탈(반복, 팔별)   feature = 2D elbow_torso_fwd(어깨–골반 선에서 팔꿈치까지 수직거리의 앞 성분 ÷ 몸통 px, 뷰 등급 B/D 로 부호)
   창 = 수축 구간(사이클 최소 + 10° 아래) 중앙값, 기준 = 세트 시작 자세(첫 상단 창 중앙값)
   코칭 문장(ship, 음성)  : 값 ≥ 시작 + 0.07  이고  절대 ≥ 0.09  (오탐 ≈ 5 %, 검출 ≈ 0.8)
   횟수 차단(COACH)       : 값 ≥ 시작 + 0.12  이고  절대 ≥ 0.12  (오탐 ≤ 2 % 목표 — 폰 라벨 세트로 확정)
   유보 = 정면(C)·측면·먼 팔꿈치 vis < 0.5(D 에서 6 %)·수축 프레임 0개

몸통 반동(반복)   2D 사선 몸통 기울기 비, 수축 − 이완 변화 ≥ 0.10(≈ 8°, 정상 초과 0~1.2 %) — beta(검출 근거 없음: AIHub 연기자도 몸통을 안 썼다)
어깨 으쓱         exclude 유지(GT 로도 MediaPipe 최선 AUC 0.67~0.74)

```
- 왜 2단인가: 원칙 #6(오탐이 사용자를 잘못 교정시킨다)은 음성을 보수적으로 하라는 것이고, 횟수 게이트는 오탐 하나가 한 회를 지우므로 더 보수적이어야 한다. 이탈 신호는 발 너비(0/243)만큼 깨끗하지 않아 한 운영점으로 둘 다 만족시킬 수 없다.
- 세트 평균 규칙(`팔꿈치 위치 고정`, 월드 R, 0.193)은 반복 검사가 서면 `supersedes` 로 beta 로 내린다(정상 세트 오탐 16 %).

## 5. 결정이 필요한 것
① 교대 컬 표시 단위(왼+오른 = 1회 / 팔당 1회). ② 2단 게이트(코칭 5 % · 차단 2 %) 수용 여부 — 하나로 합치면 차단 오탐 5 % 를 감수하거나 코칭 검출 0.65 로 내려간다. ③ 폰 라벨 세트를 찍을 수 있는지(§6) — 없으면 이탈 검사는 beta 로만 나간다.

## 7. 구현 순서(승인 후)
1. 팔별 카운터(`RepHysteresis` 새 코어, `elbow_L/R`, min(nL,nR), 교대/동시 자동) — 설계 §18.3 을 앱에 켠다. 로그에 팔별 사이클.
