# 개인화·운동 진행 UX 구현 체크포인트

> 이 문서는 §41 당시 기록이다. **준비/반복 운동의 시간 자동 종료와 화면 배치는 [§42 구현](THUMB_FIRST_UX_IMPLEMENTATION.md)으로 대체됐다.** 아래 설치·테스트 결과는 이전 APK에 관한 것이다.

2026-09-11. 사용자 요청: §40 설계를 구현하면서 촬영 방향 안내, 횟수 기반 시간/세트 간 휴식 설정, 자동 진행/건너뛰기, 불필요한 화면/음성 제거를 함께 적용한다.

## 결정

- 운동의 정답 기준과 초기 수행 비교를 분리한다. 항목별 관측이 가능하면 개인 기준을 수집한다.
- 운동별 촬영 안내는 준비 화면에서 한 번 전달한다. `OO 자세 평가를 시작합니다`, 준비 완료/측정 중 반복 발화는 제거한다. 실제 필요한 재배치/지속 변화만 안내한다.
- 반복 운동 시간은 목표 횟수 × 사용자가 조정할 수 있는 1회 소요 시간. 유지 운동은 지정한 초. 의학적 최적 속도가 아닌 실행 기본값이다.
- 준비 → 운동 세트 → 세트 사이 휴식 → 다음 세트/운동. 마지막 세트 뒤 같은 운동의 휴식을 추가하지 않는다. 모든 실행 타이머는 0에서 자동 진행, 일시정지/건너뛰기 제공.
- 운동 설정에서 횟수/시간, 세트, 1회 소요 시간, 세트 간 휴식을 저장한다. 기존 문자열 계획을 읽을 수 있게 새 필드에는 기본값을 둔다.
- 자동 마감 전에 자세 리포트를 동기적으로 확정한다. 각 세트에 별도 ID를 부여하고 건너뛴 세트를 완료로 기록하지 않는다.
- 주요 화면은 운동명·세트·남은 시간·핵심 피드백 하나. REC/프레임 수/규칙 개수/전체 자세 문단/단위 설명은 기본 노출에서 제거하고 관련 상세만 접어서 제공한다.

## 순서 / 현재 상태

1. 시간 계산/세트 진행 도메인 + 저장·설정 UI — 구현, JVM 검증 완료
2. 준비/휴식/운동 화면 + 자동 마감·건너뛰기 — 구현, 실기기 자동 전환/정지/건너뛰기 검증 완료
3. 전체 운동 프로필·개인 비교 공통 엔진 — 57개 등록(55개 카메라, 2개 타이머), 항목별 기준/관측 창 구현
4. 자세 화면·음성 정리·촬영 가이드 — 구현, 단말 캡처 확인 완료
5. 요구사항 테스트·빌드·실기기 UI/자산 확인 — JVM 213건 통과, Note10+ 실제 루트 UI 1건 + 플랭크 자산 2건 통과. UI에서 가려진 완료 버튼을 수정하고 재검증함

기존 사용자 변경을 보존하며 커밋/푸시하지 않는다. §40의 전체 연구 계획 중 새 정상 밴드 산출/임계값 재보정은 이 배포의 완료 범위에 넣지 않는다. 기존 표본·규칙을 유지하며 관측 기준 수집/변화 비교와 운동 진행 UX를 연결한다. 데이터가 없는 운동의 정자세 정확도가 검증됐다는 뜻이 아니다.

## 시간의 의미와 기본값

`횟수 × 1회 소요 시간 × 세트 + 휴식 × (세트−1)`을 계획 카드와 실제 실행에 함께 쓴다. 준비는 카메라 15초/일반 5초로 따로 둔다. 자동 카운터는 참고 측정이며 세트 타이머를 몰래 줄이거나 완료 조건으로 쓰지 않는다.

- 반복 속도: 기본 3초, 스쿼트/런지/데드리프트 계열 일부 4초, 빠른 유산소 일부 2초. 설정 범위 1~15초.
- 휴식: 주요 중량 복합 운동 120초, 일반 근력 60초, 코어 45초, 유산소/회복 30초. 0~600초로 조절 가능.
- 초/분 유지 운동은 입력 시간을 그대로 사용한다. 마지막 세트 뒤 휴식은 없으며 0초 휴식은 별도 화면을 만들지 않는다.

이 값은 운동 강도/목표/사용자의 속도를 모르는 상태의 실행 기본값이다. ACSM의 [2009 지침](https://pubmed.ncbi.nlm.nih.gov/19204579/)은 목적에 따라 속도와 휴식이 달라짐을 명시한다. 해당 지침에서 모든 운동 이름별 최적 시간을 얻었다고 해석하지 않는다. AIHub의 재생 간격 600ms로 실제 반복 시간을 추정하지 않았다.

## 개인 기준의 적용 범위

- 초반 3회 또는 유지 5초를 항목별로 수집한다. 가려진 항목은 나중에 합류할 수 있고 초기값은 고정된다. 정자세 규칙을 통과해야 저장하는 플랭크 게이트를 제거했다.
- 교대/빠른/미검증 단계는 좌우별 피처의 3초 관측 창 범위를 3개 수집한다. 이 결과를 완료 반복이나 같은 반복 단계라고 부르지 않는다.
- 바닥 측별 2D 기하는 어깨/골반과 해당 팔·다리만 필요로 한다. 반대쪽 가림 때문에 전체 항목을 버리지 않는다. 기존 규칙 피처 의미와 임계값은 바꾸지 않았다.
- 기준 재설정은 새 번호를 부여하며 변화 이력을 보존한다. 플랭크 좌우 관측 전환도 해당 쪽 기준을 따로 유지한다. 모드는 동일 수치의 표시/발화만 바꾼다.
- 구형 교정 기준선 파일은 촬영 방향·운동 변형·피처 버전이 없어 라이브에서 자동 보정에 사용하지 않는다. 파일과 개발용 수집 기능은 보존한다. 새 정답 임계값 학습을 수행하지 않았다.

## UX 결정

준비 화면: 운동·현재 세트/목표·촬영 위치·짧은 배치 설명·카운트다운. 세트 시작은 짧은 신호음, 휴식 시작은 한 문장만 안내한다. 카메라 방향 오류/가림과 지속적인 교정/변화는 운동 중에 알린다.

라이브: 모드·현재 세트·남은 시간·검출 반복·이번 안내를 우선 노출한다. REC/누적 프레임/규칙 개수와 바닥 측정 문단을 기본 화면에서 제거했다. 촬영 범위, 참고/개인 수치, 기준 재설정은 ‘측정 상세 · 촬영 안내’에 둔다. 알려지지 않은 부위를 정상으로 바꾸지 않는다.

‘세트 완료’는 사용자가 마쳤음을 뜻하고 ‘건너뛰기’는 미완료다. 타이머 0은 예정 세트 완료로 처리한다. 리포트를 먼저 확정한 뒤 다음 단계와 기록으로 전달하며 세트마다 별도 키를 사용한다.
