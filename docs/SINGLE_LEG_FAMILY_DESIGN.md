## 4. 엔진 — `posture/LegCycle.kt`

**기하(`LegGeometry.features`, 무상태)**: `thigh_L/R`(중력 기준 허벅지각, 180 = 내림), `rel_yaw`, `leg_cross`(발목 교차, 사용자 좌우는 어깨 x 차 부호), `leg_hipshift`(골반 x 의 두 발목 사이 위치), `leg_lift_L/R`(반대 발 대비 발 높이), `hip_hike_L/R`(2D 골반선 들림), `knee_out2d_L/R`, `head_lean_L/R`(귀선 − 어깨선 기울기), `hand_ear_L/R`, `elbow_knee_L/R`, `leg_hip_y`, `leg_torso2d`, **v3** `lat_flex_L/R`(측굴: 어깨선 − 골반선 기울기, 그 쪽으로 +), `knee_fwd_foot_L/R`(무릎이 발 방향으로 나간 거리 ÷ 정강이, 3D). 2D 는 IMU 롤로 되돌린다. 허리·깊이·옆으로 올림은 `PostureCore` 의 `torso_pitch`·`hip_height_rel`·`knee_lat_L/R` 을 그대로 쓴다.

**추적기(`LegCycleTracker`)** — 다리마다(크로스는 교차 하나) 1차원 사이클:
- 기준: 준비 카운트다운(`prepare`) 또는 세트 중 정지(0.4 s·3프레임, 각 신호 퍼짐 ≤ 12°)의 중앙값. **복귀마다 재기준**(체류 프레임 중앙값, 종전과 25° 안). 로그 `reps.config.standing`(v3 부터 선택 키 `torso_pitch`·`lat_flex_L/R` 도 — 허리·측굴의 서 있는 값), 재생기 `restoreStanding`.
- 출발: 무릎 ≤ 기준 − 30 / 허벅지 ≤ 기준 − 25 / 교차 ≤ −0.15. 극점 = 최소 프레임(피처 스냅샷). 복귀: 기준 − 15 안(교차는 ≥ 0.05 이고 두 무릎 ≥ 145) 에서 150 ms·2프레임 체류.
- 관절 누락 프레임은 건너뛴다. 750 ms 공백은 진행 후보만 버린다(기준 유지). 10 s 안 돌아오면 `timeout`.
- 사이클 중 수집: 극점 스냅샷(신호 최소 프레임 — 니업·크런치의 극점 무릎·무릎 바깥 위치는 여기서), 몸통 전후 기울기의 출발값·최대, 골반 높이 최소, 크로스의 더 굽은 무릎 최소, 크런치의 팔꿈치–무릎 최소(판정 프레임에 `elbow_knee_min_{s}` 가 있으면 그것 — 앱이 85 ms 프레임에서 모은 최솟값, §98a)·측굴 최대.
- **접촉 최솟값(`ContactMinimum`, 앱 전용)**: 85 ms 추론 프레임마다 팔꿈치–무릎을 받아 판정 프레임 사이의 최솟값을 모으고, 연속 세 표본의 가운데가 국소 최소이면 대칭 V 로 표본 사이의 꼭짓점을 추정한다(`m = y1 − |y0 − y2| / 2`, 0 아래 금지). 250 ms 넘는 끊김·값 없는 프레임(가려짐)은 세 표본의 연속을 끊는다 — 가려짐을 닿음으로 읽지 않는다. 준비·일시정지·사람 없음에서 비운다. 세트 로그 프레임 피처에 남아 `.fcap` 재생은 파리티, `.cap` 재생은 300 ms 값으로 후퇴한다.
- 복귀 확정 때 §3 의 판별 → 발표(`RepCycle.side` = 그 다리) 또는 기각(`reps.rejected[].feature`). 사유는 **첫 사유만** 말하므로 순서가 곧 우선순위 — 사이드 런지: `shallow` → `squat_like` → `foot_lifted` → `no_direction` → `no_shift` → `knee_over_toe` → `torso_bent`(얕은 회는 비대칭도 작아 스쿼트로 잘못 말했다). 크로스: `no_cross` → `no_descent` → `shallow` → `torso_bent`. 니업: `knee_straight` → `shallow` → `no_lift` → `both_legs` → `torso_bent`(편 다리 킥은 허벅지도 얕게 읽혀 높이를 먼저 물으면 이유가 틀린다). 크런치: `knee_straight` → `no_abduct` → `no_elbow` → `no_crunch` → `shallow` → `no_lift` → `both_legs` → `torso_bent`. 재료가 없는 조건(골반 높이·몸통·측굴·무릎 바깥 위치)은 통과한다. `timeout` 10 s.
- 기각 음성(`LegCycleTracker.cueFor`, 두 모드, 6 s 간격): 얕게 — "더 깊게 앉아야 세요"(사이드) / "더 깊게 내려가야 세요"(크로스) / "무릎을 골반 높이까지 올려야 세요"(니업) / "무릎을 더 높이 옆으로 올려야 세요"(크런치); 허리 — "허리를 숙이면 세지 않아요. 가슴을 들고 상체를 세워 주세요"(런지) / "… 가슴을 펴고 몸통을 세운 채 올려 주세요"(니업) / "앞으로 숙이면 세지 않아요. 몸통을 세운 채 옆구리만 접어 주세요"(크런치); 편 다리 — "다리를 뻗으면 세지 않아요. 무릎을 접은 채 올려 주세요" / "… 무릎을 굽힌 채 옆으로 올려 주세요"; 앞으로 — "앞으로 올리면 세지 않아요. 무릎을 옆으로 올려 주세요"; 다리만 — "다리만 올리면 세지 않아요. 옆구리를 접어 팔꿈치가 무릎에 닿아야 세요"; 들림 — "발이 바닥에서 더 떠야 세요 …"; "발이 교차해야 세요", "교차한 뒤 무릎을 굽혀 내려가야 세요", "한쪽 무릎만 굽혀야 세요", "몸을 굽힌 다리 쪽으로 옮겨야 세요". 그 밖(`no_direction`·`foot_lifted`·`both_legs`·`no_elbow`·`timeout`)은 낮은 틱만. HUD "세지 않은 동작 n".

## 9. v1(§96)·Codex(§93) 과의 차이

둘 다 발의 위치 변화로 세려 했고 둘 다 이 사용자의 런지를 0회로 셌다. v2 는 발 위치를 아예 쓰지 않는다. 니업·크런치의 "얕은 회·다리만" 은 세 버전 중 v2 만 거른다. 단위는 v2 만 네 종목 전부 짝이다.
