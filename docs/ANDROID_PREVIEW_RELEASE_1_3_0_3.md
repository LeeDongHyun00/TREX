# Android 체험판 1.3.0-preview.3

2026-09-28 · main · 태그 `v1.3.0-preview.3`

## 새 기능

- 홈의 운동 시작·식단 기록 아래에서 **근육 피로도**를 열 수 있습니다. 수행 기록과 경과 시간을 바탕으로 부위별 부하를 추정하고 3D 근육도에 표시합니다.
- 현재 카탈로그의 **26종 운동**을 근육군에 연결했습니다. 반복·시간·좌우 기록을 반영하고, 맨몸 운동은 당시 키·체중을 제한적으로 보정합니다. 자세 정확도를 피로 배율로 사용하지 않습니다.
- 부위별 상태와 최근 반영 기록을 확인하고, 추정 부하를 고려한 추천 운동을 루틴에 추가할 수 있습니다.
- 운동 마무리 화면의 **사용 근육**은 이번 운동에서 사용한 부위를 선명하게 보여 줍니다. 누적 피로 점수와는 구분된 표시입니다.
- 두 화면에서 3D 근육도를 드래그해 원하는 방향으로 돌려 볼 수 있습니다.

## 화면과 모델 개선

- 피로도 범례를 TREX 회색·라임·그린 스펙트럼 바로 정리하고, 아래 양끝에 ‘낮음’과 ‘높음’을 표시합니다.
- 완료 화면 제목을 3D 카드 밖에 배치하고 설명을 간결하게 정리했습니다. 내용이 화면보다 길 때만 스크롤되며, 모델 양옆에 페이지 스크롤을 시작할 여백을 남겼습니다.
- 완료 화면에서 3D가 빈 배경으로 보이던 높이 계산 문제를 수정했습니다.
- 모델의 엉덩이 사이 연결층 돌출과 양손 약지 끝부분을 다듬었습니다.
- 운동 페이지 ‘오늘의 루틴’ 배경을 다크 모드에 맞췄습니다.

## 기록과 해석

- 세트 원본과 근육별 부하를 기기 내 SQLite에 보관합니다. 기존 기록 가져오기, 중복 방지, 부분 수행, 횟수 수정과 시간 경과에 따른 재계산을 지원합니다.
- 표시값은 **운동 기록 기반 추정치**입니다. 실제 생리학적 피로·근손상·회복 완료를 측정하거나 보장하지 않습니다. 외부 중량, 수면·영양 등 미입력 요인과 개인차를 모두 반영하지 못합니다. 계수는 문헌의 운동 역할을 참고한 제품 초기값입니다.
- 이번 APK에는 최신 main에 병합된 음식 영역 인식·내 음식 기억 개선도 포함됩니다.

## 배포 및 검증

- 패키지 `com.example.trex_kotlin`, versionCode **8**, versionName **1.3.0-preview.3**. Android 8.0 이상.
- JVM 단위 테스트 **504건 통과**(실패·오류·건너뜀 0). 릴리스 APK와 Android 테스트 APK 빌드 성공. PC SQLite 제약 검사 통과.
- 앞선 작업에서 실제 앱 자산의 PC 3D 색 표시·회전과 Blender 전후 표면을 확인했습니다. 이번 배포에서는 Android 계측 테스트를 다시 실행하지 않았습니다. **실휴대폰 화면 검증은 수행하지 않았습니다.**
- 기존 체험판과 같은 개발 인증서로 릴리스 변형 APK를 서명했습니다. 정식 운영 서명 배포는 아닙니다. 인증서 SHA-256: `3027771596e23100d4203da03cd44c4a81f5e3d4cf197fdb7fb2ba4e4dc751ef`.
- APK와 `SHA256SUMS.txt`, 커밋·빌드 정보를 담은 `BUILD_INFO.json`을 릴리스 자산으로 제공합니다. 소스 저장소에는 APK·키·개인 기록을 넣지 않습니다.
- 기존 동일 서명 앱 위에 업데이트할 수 있습니다. 이전 버전으로 돌아가려고 앱을 삭제하면 기기 기록이 사라질 수 있으므로, 문제가 있으면 기록을 보존한 후 수정 버전으로 업데이트합니다.
