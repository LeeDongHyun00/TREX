# Android 체험판 1.3.0-preview.7

2026-10-10 · 브랜치 `redesign` · 태그 `v1.3.0-preview.7`

크런치·레그 레이즈·플랭크 운동 가이드와 preview.6 이후의 자세·횟수·시선 안내 개선을 담은 체험판입니다.
패키지는 `com.example.trex_kotlin`, versionCode는 **12**이며 Android 8.0 이상에서 설치할 수 있습니다.

## 운동 가이드

- 크런치·레그 레이즈·플랭크에 시작 자세·운동 동작·호흡법·주의사항을 추가했습니다.
- 운동 목록과 세션의 **운동 방법**에서 같은 두 탭 안내를 볼 수 있습니다. 첫 준비 안내도 기존 흐름을 따릅니다.
- 크런치와 레그 레이즈는 두 프레임 GIF, 플랭크는 선택한 **첫 번째 프레임의 정지 이미지**를 표시합니다.
- 레그 레이즈는 바닥에 누워 두 다리를 함께 드는 동작, 플랭크는 전완 지지 자세를 안내합니다.
- 생성 시범은 연속 촬영이나 전문가 검수를 거친 교육 영상이 아닙니다. 교육 설명을 카메라 판정 근거로 사용하지 않습니다.

## 자세·횟수·촬영 화면

- 바닥 운동의 크런치·레그 레이즈 반복 추적과 플랭크 유지 시간 처리를 개선했습니다.
- 스쿼트 복귀 구간과 발끝·무릎 벌림 검사, 덤벨 컬·런지·한 다리 운동의 판별과 교정 안내를 보완했습니다.
- 말하기 대기열과 준비 안내를 정리해 설명·교정 멘트가 겹치거나 세트 끝에서 잘리는 상황을 줄이도록 변경했습니다.
- 바닥 세 종목에 얼굴 모델을 사용한 시선 벗어남·복귀 안내를 추가했습니다. 반대쪽 방향까지 구분한다고 안내하지 않습니다.
- 세션 중 폰의 방향에 맞춰 가로·세로 배치를 전환하고 교정 화살표·뼈대 표시를 보완했습니다.

## 업데이트

기존 체험판과 같은 개발 인증서로 서명합니다. preview.6의 앱 내 업데이트가 버전 코드 12를 새 버전으로 인식하며,
`BUILD_INFO.json`의 인증서와 APK 해시를 대조합니다. 같은 서명 앱 위에 업데이트하면 기존 기록을 유지할 수 있습니다.
앱의 확인 간격은 6시간이고 설치 자체는 Android 패키지 설치기가 담당합니다.

릴리스 자산은 `TREX-1.3.0-preview.7.apk`, `SHA256SUMS.txt`, `BUILD_INFO.json`입니다.
APK·서명키·개인 기록은 소스 저장소에 포함하지 않습니다.

## 검증 범위와 남은 확인

로컬 앱 JVM 단위 테스트 **704건**, 재생기 테스트 **144건**, `setlog_captures.py --self-test` **54/54**가 통과했습니다.
실패·오류·건너뜀은 0건이며 `:app:assembleRelease`와 release 필수 lint 검사가 성공했습니다.
앞선 가이드 구현에서 Android 테스트 APK 컴파일도 성공했습니다. 이번에는 계측 테스트를 실행하지 않았습니다.
APK의 패키지·버전 코드 12·버전 이름과 크런치·레그 레이즈 GIF·플랭크 정지 PNG의 원본 해시를 확인합니다.
플랭크 GIF는 패키지에 포함하지 않습니다.
서명 검증을 통과했고 인증서 SHA-256이 preview.6과 동일합니다:
`3027771596e23100d4203da03cd44c4a81f5e3d4cf197fdb7fb2ba4e4dc751ef`.
빌드 커밋·APK 해시·서명·검증 범위는 릴리스 자산 `BUILD_INFO.json`에 기록합니다.
이번 릴리스의 폰 설치와 실제 화면·운동 세션 검증은 수행하지 않습니다. 사용자가 폰 재설치를 제외했습니다.

일부 자세·판별 기준은 폰 라벨 검증 중입니다. 관절 추정의 가림·좌우 뒤바뀜·촬영 배치 때문에
반복이나 유지 시간이 실제 수행과 다를 수 있으며, 깊이·허리 접지·시선의 모든 오류를 관측하지 못합니다.
스쿼트 무릎 벌림 차단은 사용자 정의 기준이며 일부 정상 수행도 차단할 수 있습니다.
가이드의 추가와 단위 테스트 통과를 실기기 자세 평가 성능 검증으로 해석하지 않습니다.

설계·구현 근거는 `docs/CORE_EXERCISE_GUIDE_DESIGN.md`, `docs/PHONE_REPORT_2026-10-08_DESIGN.md`,
`docs/GAZE_DESIGN_2026-10-09.md`, 정본 스펙 §99b~§106에 있습니다.

## 문제 발생 시

설치 불가·앱 실행 불가·기록 손실이 확인되면 릴리스를 초안으로 전환해 앱 내 업데이트 노출을 중단합니다.
기록을 보존하면서 같은 서명의 더 높은 버전 코드 수정판을 배포합니다.
