# 크런치·레그 레이즈·플랭크 운동 가이드 설계

2026-10-10 · **구현·JVM 검증·연결 폰 업데이트 설치 완료 / Android 화면 검증은 사용자 담당**

`redesign`의 기존 운동 방법 시트를 재사용하고, 세 종목의 설명과 전용 시범 자산을 추가한다.
현재 플랭크는 사용자 선택에 따라 첫 프레임 PNG를 표시한다(§11). 아래 초기 GIF 제작 계획과 §9·§10은 단계별 기록이다.
화면 양식은 기존 7종목과 같으며, 플랭크의 시범은 자세를 유지하는 모습을 보여준다.
이 문서는 바로 구현에 사용할 문구 초안·자산 제작 조건·연결 위치·완료 기준을 정의한다.

## 1. 기준 코드와 범위

설계 기준은 원격 `redesign`의 `293f8fce44fb433c2818af80ee0ebe03cd3d7441`이다.
작업 브랜치는 `codex/core-exercise-guides-design`이다. 설계 후 사용자 요청으로 세 레코드와 전용 GIF를 추가했다.

- 현재 가이드: 기본 스쿼트·런지·덤벨 컬·크로스 런지·사이드 런지·스탠딩 니업·스탠딩 사이드 크런치.
- 추가 가이드: 카탈로그에 이미 있는 **크런치·레그 레이즈·플랭크**.
- 레그 레이즈의 범위는 바닥에 누워 두 다리를 함께 드는 동작이다. 행잉 레그 레이즈에는 연결하지 않는다.
- 플랭크의 범위는 팔꿈치·전완·발끝으로 지지하는 기본 전완 플랭크다.
- 기존 [운동 가이드 UI](EXERCISE_GUIDE_UI.md) §66·§91과
  [자산 제작 양식](../app/src/main/assets/exercise_guides/README.md)을 따른다.
- 카탈로그의 횟수·시간·세트·휴식, 자세 교정 스위치, 촬영 안내, 판정·점수·음성 정책은 이 기능의 입력이 아니다.

## 2. 같은 화면으로 제공하는 방법

다음 구성은 기존 `ExerciseGuideSheet`의 실제 배치다. 새 전용 화면을 만들 필요가 없다.

```text
운동 목록 / 운동 추가 화면
  └─ 운동 방법
       ┌─────────────────────────────────┐
       │ 운동 이름                        │
       │ 운동 방법                        │
       │                                 │
       │     흰 배경의 운동별 GIF          │
       │                                 │
       │ [운동 가이드]  [주의사항]          │
       │ 시작 자세                        │
       │ 운동 동작                        │  ← 본문 스크롤
       │ 호흡법                           │
       │ 시범 각도 / 촬영 방향 안내         │
       │─────────────────────────────────│
       │          닫기                    │  ← 하단 고정
       └─────────────────────────────────┘
```

- TREX 테마, 제목 24sp, 본문 14sp/줄 높이 22sp, 흰 GIF 영역 260dp,
  고정 높이 660dp 시트, 두 탭, 하단 버튼을 기존 컴포넌트에서 그대로 받는다.
- 주의사항 탭에서는 같은 GIF 아래에 주의 문장만 표시한다.
- GIF는 열려 있는 동안 자동 재생하며 앱이 배경으로 가면 멈춘다. 재생 조작·코멘트·출처 링크는 추가하지 않는다.
- 기존 안내인 “시범의 각도와 권장 촬영 방향은 다를 수 있어요.”를 유지한다.
- 작은 화면과 큰 글꼴에서는 기존 본문 스크롤과 하단 버튼이 실제로 접근 가능한지 확인한다.
  기존 고정 높이가 잘리는 문제를 발견하면 공통 시트의 높이 처리를 별도 수정 대상으로 기록한다.

### 진입과 세션 상태

| 진입 | 기존 정책을 세 운동에도 적용 |
|---|---|
| 운동 목록·종목 선택 | 해당 종목의 시트만 열고 루틴 선택·수정·세션 상태를 바꾸지 않는다. |
| 처음 수행하는 종목의 준비 | `ExerciseGuides.introduction()`이 안내를 연다. 초기 구성부터 준비·측정·시간·자동 전환을 보류한다. |
| 첫 안내에서 준비 계속하기 | 해당 종목을 `exercise_guides/seen_v1`에 기록하고 준비로 돌아간다. |
| 준비·운동·휴식에서 수동 다시 보기 | `showGuide()`로 일시정지하고 진행 중 음성을 멈춘다. 닫은 뒤에는 직접 재개한다. |
| 뒤로가기·바깥 영역으로 닫기 | 기존 `closeGuide(false)` 정책대로 정지 상태를 유지한다. 시트 드래그는 비활성이다. |
| 앱이 배경으로 이동 | GIF와 세션 진행을 기존 수명주기 정책으로 보류한다. |

목록 미리보기는 첫 준비의 확인 기록을 쓰지 않는다. 사용자가 목록에서 읽었어도 첫 준비 안내는 표시된다.
세션에서 안내를 닫는 모든 경로는 현행 `closeGuide()`대로 해당 종목을 확인 기록에 남긴다.
세 종목은 새 이름이므로 기존 7종목의 확인 기록을 초기화하거나 설정 버전을 올릴 필요가 없다.
플랭크에서는 가이드를 보는 동안 목표의 남은 시간과 인정된 유지 시간도 증가하지 않아야 한다.

## 3. 등록 데이터와 연결 구조

현재 `ExerciseGuide(name, asset, comment, setup, steps, breathing, cautions, sourceName, sourceUrl)`로
세 종목을 모두 표현할 수 있다. 유지 동작도 `steps`에 준비→유지→종료를 적을 수 있으므로 새 필드는 추가하지 않는다.

| 앱의 정확한 이름 / `name` | `asset` | 설명하는 동작 | `sourceName` |
|---|---|---|---|
| 크런치 | `exercise_guides/crunch.gif` | 상체를 작게 말아 올린 뒤 복귀 | `ACE · Crunch` |
| 레그 레이즈 | `exercise_guides/lying-leg-raise.gif` | 누운 상태에서 두 다리 함께 올리기·내리기 | `Norfolk and Suffolk NHS · Double leg raises` |
| 플랭크 | `exercise_guides/forearm-plank.png` | 전완과 발끝으로 지지하며 유지, 첫 프레임 정지 이미지 | `ACE · Front Plank` |

`sourceUrl`은 아래 종목별 원문 링크를 사용한다. `comment`는 아래 한 줄 설명을 저장하되
현재처럼 화면에는 표시하지 않는다. `setup`·`steps`·`breathing`·`cautions`가 탭 본문이다.

```text
카탈로그의 workout.name
  → ExerciseGuides.forName()의 정확한 이름 조회
  → 목록·선택: ExerciseGuidePreview → ExerciseGuideSheet
  → 세션: introduction / showGuide → activeGuide → ExerciseGuideSheet

ExerciseGuide.asset
  → Android assets → Movie 디코드 → 기존 ExerciseGifView 자동 재생
```

등록과 파일 패키징을 같은 변경에 포함한다. 그림이 없는 이름만 먼저 등록하거나 다른 운동 GIF를 대신 쓰지 않는다.
디코드 실패 시 기존 실패 문구와 설명·닫기 버튼을 제공한다. 원격 다운로드·새 서버·DB·미디어 라이브러리는 필요하지 않다.

## 4. 운동별 문구 초안

다음 문구는 한국어로 요약·재작성한 교육용 안내이며, 앱의 판정 임계값을 설명하지 않는다.

### 4.1 크런치

근거: [ACE · Crunch](https://www.acefitness.org/resources/everyone/exercise-library/52/crunch/).
무릎을 굽히고 발을 바닥에 둔 자세, 상부 등의 작은 들림, 통제된 복귀와 호흡을 적용한다.
손은 머리 뒤에서 귀 옆으로 옮겨 당기지 않도록 안내한다. 숫자로 된 거리·각도는 요구하지 않는다.

**한 줄 설명 (`comment`)**: 복부에 힘을 주어 상체를 작게 말아 올리는 운동입니다.

**시작 자세 (`setup`)**

1. 매트에 등을 대고 누워 무릎을 굽히고 두 발바닥을 바닥에 두세요.
2. 손끝을 귀 옆에 가볍게 대고 팔꿈치를 열어 두세요. 목과 어깨의 힘을 빼세요.

**운동 동작 (`steps`)**

1. 복부에 힘을 주며 갈비뼈를 골반 쪽으로 가까이 가져가듯 상체를 천천히 말아 올리세요.
2. 상부 등이 매트에서 살짝 들리면 잠시 멈추세요. 발과 골반은 바닥에 두세요.
3. 상체를 천천히 내려 시작 자세로 돌아오세요.

**호흡법 (`breathing`)**: 상체를 올릴 때 내쉬고, 내려올 때 들이마시세요. 숨을 참지 마세요.

**주의사항 (`cautions`)**

1. 손으로 머리나 목을 당기지 마세요.
2. 윗몸일으키기처럼 상체를 끝까지 세우거나 반동을 쓰지 마세요.
3. 발과 골반을 바닥에 두세요. 목이나 허리에 통증이 생기면 중단하세요.

### 4.2 레그 레이즈

근거: [Norfolk and Suffolk NHS · Double leg raises](https://www.nsft.nhs.uk/help-for-your-body-and-mind/),
본문의 같은 이름 동작 설명. 두 다리 동시 수행·등의 접지·천천히 내리기를 적용한다.
원문은 아동·청소년 대상 홈 운동 묶음이며, 이 설계에는 동작 설명만 가져온다.
원문의 수직 도달·바닥에 닿지 않기는 개인의 필수 달성 조건으로 옮기지 않는다.
호흡과 통증 시 중단은 [Mayo Clinic 근력운동 원칙](https://sportsmedicine.mayoclinic.org/news/weight-training-dos-and-donts-of-proper-technique/)을 적용한 안내다.

**한 줄 설명 (`comment`)**: 몸통을 안정시킨 채 두 다리를 함께 올리고 내리는 운동입니다.

**시작 자세 (`setup`)**

1. 매트에 등을 대고 누워 머리와 어깨를 편하게 내려놓으세요.
2. 팔은 몸 옆에 두고 손바닥을 바닥에 대세요. 두 다리를 나란히 펴고 복부에 힘을 주세요.

**운동 동작 (`steps`)**

1. 머리와 몸통을 바닥에 둔 채 두 다리를 함께 천천히 들어 올리세요.
2. 골반을 안정적으로 유지할 수 있는 높이까지 올리세요.
3. 허리가 과하게 뜨지 않는 범위까지 두 다리를 함께 천천히 내려 반복하세요.

**호흡법 (`breathing`)**: 다리를 올릴 때 내쉬고, 내릴 때 들이마시세요. 숨을 참지 마세요.

**주의사항 (`cautions`)**

1. 다리를 낮출 때 허리가 뜨거나 몸통이 흔들리면 내려가는 범위를 줄이세요.
2. 다리를 번갈아 들거나 무릎을 가슴 쪽으로 접지 마세요. 두 다리를 함께 움직이세요.
3. 반동으로 다리를 던지지 마세요. 허리나 고관절에 통증이 생기면 중단하세요.

무릎을 크게 굽힌 대체 동작을 이 종목의 정상 시범에 섞지 않는다.
해당 변형을 지원하려면 별도 종목 범위와 판별 정책을 정해야 한다.

### 4.3 플랭크

근거: [ACE · Front Plank](https://www.acefitness.org/resources/everyone/exercise-library/32/front-plank/).
어깨 아래 팔꿈치·전완 지지, 몸통과 다리의 안정, 유지 중 호흡과 천천히 종료하기를 적용한다.
유지 시간은 개인 목표를 사용하며 원문의 시간을 새 기본값으로 넣지 않는다.

**한 줄 설명 (`comment`)**: 전완과 발끝으로 몸을 지지하며 몸통을 안정적으로 유지하는 운동입니다.

**시작 자세 (`setup`)**

1. 매트에 엎드려 팔꿈치를 어깨 바로 아래에 놓고 전완을 바닥에 대세요.
2. 발끝을 바닥에 대고 다리를 펴세요. 복부에 힘을 주고 시선은 바닥에 두세요.

**운동 동작 (`steps`)**

1. 전완과 발끝으로 바닥을 밀며 몸통을 천천히 들어 올리세요.
2. 머리부터 발뒤꿈치까지 길게 이어지는 자세를 유지하세요.
3. 자세를 유지하기 어려워지면 몸을 천천히 내려 쉬세요.

**호흡법 (`breathing`)**: 유지하는 동안 자연스럽게 들이마시고 내쉬세요. 숨을 참지 마세요.

**주의사항 (`cautions`)**

1. 허리가 처지거나 엉덩이가 높이 올라가지 않도록 몸통을 안정시키세요.
2. 어깨를 귀 쪽으로 움츠리지 말고 팔꿈치 위에서 지지하세요.
3. 목표 시간을 채우려고 무너진 자세로 버티지 마세요. 통증이 생기면 중단하세요.

## 5. 같은 스타일의 GIF 제작 명세

출력은 세 개의 **로컬 GIF**다. 기존 자산과 같은 640×640 정사각형,
흰 배경·회색 해부학 인물·검은 반바지·맨발·복부의 절제된 붉은 강조를 쓴다.
같은 운동의 두 프레임은 인물·크기·카메라·조명·매트 위치가 같아야 한다.
머리·손·발이 모두 들어가며, 두 자세를 포개었을 때 바닥 위치와 접지점이 뛰지 않아야 한다.
근육 색은 부위를 설명하는 그림이고 근활성·피로·자세 점수의 수치가 아니다.

| 자산 | 프레임 A | 프레임 B | 시점과 검수 핵심 |
|---|---|---|---|
| `crunch.gif` | 무릎 굽힘·발 접지·상체를 내린 자세 | 상부 등만 작게 말아 올린 자세 | 측면에 가까운 사선. 발·골반 위치 고정, 손으로 목을 당기지 않음, 앉은 자세가 되지 않음. |
| `lying-leg-raise.gif` | 등·머리·어깨 접지, 두 다리를 나란히 편 자세 | 두 다리를 함께 들어 올린 자세 | 측면에 가까운 사선. 양 다리가 구분되며 무릎 형태 일정, 골반을 들어 올리지 않음. |
| `forearm-plank.gif` | 팔꿈치 아래 지지점과 전신 정렬이 보이는 유지 자세 | 같은 유지 자세, 아주 작은 자연스러운 호흡 변화만 | 측면에 가까운 사선. 어깨·팔꿈치·골반·발 접지점 고정. 팔굽혀펴기·무릎 대기·골반 들기와 번갈아 보여주지 않음. |

기본 패키징은 §91과 같은 2프레임·각 900ms·무한 반복이다.
이는 두 자세를 보여주는 표시 주기이며 운동 속도나 호흡 주기를 처방하지 않는다.
특히 플랭크는 준비↔유지를 반복하는 그림이 아니라 **유지↔유지**로 보여준다.
두 끝 자세 GIF만으로 중간 동작을 검증했다고 주장하지 않는다.

### 생성 지시 템플릿

기존 `standing-side-crunch.gif`의 첫 프레임을 스타일 참고로 확인한 뒤 다음 조건으로

문헌의 그림·영상을 다운로드해 포함하지 않는다.

## 6. 자세 평가와의 관계

초기 설계 기준에서는 세 종목이 [자세 교정 시험 단계](exercises/floor_trial.md)였다.
최신 `redesign`의 시험 표시·시선·세션 방향 정책 변경은 그대로 반영하며, 가이드가 이를 다시 덮어쓰지 않는다.
시험 상태와 고지 여부는 최신 `PostureTrial` 정책을 따른다.
가이드의 존재나 문헌 기반 설명을 이유로 시험 상태를 바꾸지 않는다.

레그 레이즈 안내에는 허리 접지를 설명할 수 있지만, 카메라가 허리 접지를 판정한다고 적지 않는다.
그 관측 한계는 정본 스펙 §99b(초기 기준에서는 §100)에 기록되어 있다.
시범의 관절 각도·900ms·그림의 사선 구도를 판정 임계값이나 촬영 가이드로 옮기지 않는다.
가이드 추가를 위해 `postureExerciseMap` 또는 `Workout.postureSupported()`를 수정할 필요도 없다.

## 10. 연결 폰 업데이트 설치 (2026-10-10)

사용자가 현재 연결된 폰에 구현한 가이드를 적용하도록 요청해 앞선 임시 빌드 보류를 해제했다.
`gradlew.bat :app:testDebugUnitTest :app:assembleDebug --console=plain`이 성공했고,
단위 테스트 645건(가이드 테스트 3건 포함)이 실패·오류·건너뜀 없이 통과했다.
APK 안의 새 GIF 3개를 읽어 소스 자산의 SHA-256과 일치하는 것을 확인했다.

Galaxy Note10+(SM-N976N)의 기존 `com.example.trex_kotlin` 설치본과 새 APK의 서명이 같았다.
기존 APK·내부 저장 데이터·자세 로그를 먼저 백업한 뒤 `adb install -r`로 업데이트 설치했다(Success).
버전은 `1.3.0-preview.6` / versionCode 11이다. 설치된 APK의 SHA-256이 빌드 APK와 일치하고,
설치 전후 내부 파일 16개(기록·설정 포함)와 자세 로그 27개의 파일별 해시가 모두 같았다.

설치·보존 확인 결과와 백업은 Git에서 제외된 `outputs/core-exercise-guides/`에 저장했다.
실휴대폰 앱 실행·화면 조작·시트와 플랭크 시계의 UI 검증은 기존 역할 분담대로 사용자 담당이다.

## 11. 플랭크 첫 프레임 정지 이미지 (2026-10-10)

사용자가 플랭크의 움짤 대신 첫 번째 이미지 사용을 지정했다.
기존 GIF의 0번 프레임을 디코드해 `forearm-plank.png`로 저장했고 픽셀의 완전 일치를 확인했다.
640×640·1프레임·111,783바이트이며 기존 플랭크 GIF는 패키지에서 제거했다.
크런치·레그 레이즈와 기존 7종목은 GIF를 사용한다.

공통 시트는 GIF를 기존 `Movie`로 재생하고 PNG는 `BitmapFactory`로 디코드해
Compose `Image`에 비율을 유지하며 표시한다. 정지 이미지에는 반복 재생이나 프레임 갱신이 없다.
두 탭·본문·첫 준비 안내·가이드 확인 기록·세션 보류 동작은 기존 경로를 공유한다.
기존 JVM 자산 검사와 Android 디코드 검사를 두 형식에 맞춰 갱신했다.

첫 프레임 선택·픽셀 대조 증거는 `outputs/core-exercise-guides/plank-static.json`에 보관한다.
PNG SHA-256: `d5ff784b1a838f1d35bb1ab6af252349a61d68951e6781e98c3061cd54e2f274`.
앞선 §10 폰 설치본은 2프레임 GIF 버전이다. 이번 정지 이미지 변경은 소스 푸시 범위이며 재설치하지 않았다.

원격 `redesign`의 `ccf9f216`(spec §101f) 위에 가이드 작업을 적용했다. 문서의 절 번호 충돌을 피하도록
초기 설계·구현·설치를 정본 스펙 §102·§103·§104로 정리하고 원격 자세 작업과 이력을 모두 보존했다.

Android 테스트 APK 컴파일은 실휴대폰 UI 테스트 실행을 뜻하지 않는다.
