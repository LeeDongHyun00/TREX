## 1. 정의
- **판독 후보** (2D 는 원본 px, app 도 같은 정의): ① 발목→발끝 각 atan2(dx_바깥, |dy|) ② 뒤꿈치→발끝 각 ③ (발끝x−발목x)÷정강이px ④ (발끝x−뒤꿈치x)÷정강이px ⑤ 발 길이(뒤꿈치–발끝)÷정강이px ⑥ 월드 수평면 발목→발끝 각(up = y↑ / DLT 중력) — **앱 `toe_out_*` 이 ⑥(중력)이고 서 있는 창 중앙값**(`PostureCore.kt:281`, `RepForm.kt:527`) ⑦ 월드 뒤꿈치→발끝 각. - **GT 진실**: 발 방향 = 발목→Foot 수평각(몸 정면 z_b 기준) · **정강이 기울기** = 정면(x_b·up) 평면에서 무릎→발목이 수직에서 바깥으로 기운 각(발목이 무릎보다 바깥 = +) · 발 너비 = 발목 간격÷어깨 간격 · knee_out(앱 식) · KASR = 무릎 간격÷발목 간격.

## 4. 검출 가능성 — 어느 판독이 발끝엔 민감하고 방해엔 둔한가
- 서 있음 2D 발목→발끝(각 또는 가로 오프셋÷정강이): 발끝 15° → 14.0° / 0.087, d′ **1.53~1.58**(30° → d′ 3.1), 정강이·발 너비 부분 R² 0.00. 사람 주석 상한 1.65 와 거의 같다 → 서 있음에서 MP 는 기하 이상을 잃지 않는다.
- 뒤꿈치→발끝: 잔차 SD 13°(서 있음)·19°(바닥), 바닥 정강이 의존 최대(−0.76 °/°) → 가장 나쁜 각. 발 길이÷정강이: 발끝 정보 거의 없음(d′ 1.0/0.2). 월드: 서 있음 0.93, 바닥 0.28.

## 7. 결론
1. **가설은 절반만 맞다.** MP 는 (특히 바닥에서) 발 픽셀이 아니라 **무릎의 가로 위치** 쪽으로 발끝을 끌어 놓는다 — 정강이 선의 연장이 아니라 '무릎은 발끝 위' 사전지식이다. 사람 주석(기하)에는 없는 모델 추론이고, 폰 6회(무릎 벌림 → 49/48°)의 크기(+18~31° 예측 vs +19~23° 실측)와 맞는다.
2. **폰의 '넓게 서기 부풀림' 은 여기서 재현되지 않는다.** 서 있음에서 발 너비·정강이 의존은 기하 몫뿐이고, 꼬리(발 너비 1.5~2.0, 정강이 15°+)도 일관된 부풀림이 없다(오히려 안쪽). 남은 용의자: 바닥에 놓은 폰의 낮은 시점·근거리(발의 세로 성분 |dy| 소실), VIDEO 모드 추적, 발 너비 2.25(AIHub 최대 2.04). A6 §3.5 의 폰 실험(테이프로 발끝 고정, 폭만 변경, 높이 2가지)이 그대로 필요하다.
3. **판독 선택**: 서 있는 프레임의 **2D 발목→발끝(각 또는 가로 오프셋÷정강이 px)** 가 최선(d′ 1.5~1.6, 방해 의존 0). 앱의 월드 각은 b 0.57·d′ 0.93·정강이 +0.33 °/° 로 열세다. 뒤꿈치→발끝은 쓰지 말고, 바닥 프레임·사선 뷰도 쓰지 말 것. 바닥 거치 폰에서는 |dy| → 0 이라 각보다 **오프셋÷정강이** 가 안전하다(폰 좌표 로그 재생으로 확인 필요).
4. **유보 조건 추가 후보**: 서 있는 창의 KASR(무릎 간격÷발목 간격)이 1.0 을 넘거나 무릎 가로 오프셋이 시작 자세보다 커진 반복은 발끝 판독을 유보 — 지금의 `invalidatedBy`(발 너비)에 더한다. 띠는 폰 라벨 세트로 잰 뒤 확정(beta).

## 8. 가정·못 한 것
- GT 진실은 발목→중족부(8 cm)라 발끝이 아니다 — 사람별 상수 편향과 b 절대값 감쇠가 있다(후보 간 비교엔 공통). 바닥에서는 GT2D 주석도 b 0.33 으로 약해(가림) '기하 기준선' 이 흐리다; 차 회귀와 클립 내 변화 분석이 이를 보완한다.
- IMAGE 모드·클립당 16프레임 성긴 표본. 앱은 VIDEO 모드(추적·평활) — 시간 축 효과는 못 쟀다.
- 스튜디오 카메라(85 cm, 4 m, 수평)만. 폰의 바닥 거치·근거리 조건이 없다. 발 너비 ≥ 1.5 는 21클립/4세션, 정강이 ≥ 15°(서 있음) 21관측.
- 정강이·KASR·knee_out 은 |r| 0.7~0.87 로 얽혀 있어 확장 모형 계수는 개별 해석 불가. 부트스트랩 클러스터는 43~45 세션이라 구간이 넓다.
- 2D 각의 세로 성분 |dy| 는 카메라 높이에 따라 달라지므로 b(0.93)는 이 카메라 배치의 값이다. 시작 자세 대비 검사에서는 이득만 바뀐다.
