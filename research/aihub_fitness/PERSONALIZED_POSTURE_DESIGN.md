# 모든 운동의 개인화 자세 평가 설계

2026-09-11 · **설계안, 앱 구현 전** · 스펙 §40

목표는 현재 가진 AIHub 이미지·관절·라벨·MediaPipe 결과와 휴대폰 한 대로, 개인차를 수용하면서 교정과 수행 변화를 전달하는 것이다. 추가 데이터 수집이나 새 모델 학습을 선행 조건으로 두지 않는다. 현재 `Sheets.kt` 카탈로그 **57개**, 자세 연결 **27개 이름/26개 AIHub 종목**, 데이터에만 있는 운동도 확인했다. 전체 종목의 처리 계약은 [종목별 설계표](PERSONALIZED_POSTURE_EXERCISES.md)에 있다.

## 1. 결정

1. **평소 수행 기준과 교정용 기준을 분리한다.** 처음부터 참고 범위를 벗어나도 관측 가능한 움직임은 개인 비교 기준으로 저장할 수 있다. 그 기준을 정자세로 부르지는 않는다.
2. **모든 종목에 같은 개인화 절차를 적용한다.** COACH와 TRACK은 같은 관측·기준·판정을 읽는다. 모드 선택으로 임계값이나 개인 기준을 바꾸지 않는다.
3. **개인화의 기본은 같은 사람의 같은 단계 비교다.** 교정 임계값을 사용자별로 학습하지 않는다. 정상 데이터와 같은 피처·단위·방향에서 보정 효과가 확인된 항목에만 교정 기준선 보정을 적용한다.
4. **신체 크기는 기존 각도·신체 길이 비율로 정규화한다.** 키/다리 길이를 입력받아 정답 각도를 회귀 예측하거나 사람을 체형 군집으로 나누는 기능은 이번 설계에 넣지 않는다.
5. **한 운동의 일부 항목이 안 보여도 나머지를 계속 측정한다.** 측면 머리 가림 때문에 골반 추적을 끊거나, 반복 신호가 없다는 이유로 모든 개인 비교를 비우지 않는다.
6. **측정 변화와 교정 제안을 합산하지 않는다.** “초기보다 줄었다”와 “선택한 운동의 참고 범위보다 작다”를 독립 보존한다. 가림은 정상/복귀가 아니다.

기존 연구와의 연결: 스펙 §16의 개인별 임계값 재적합은 정직한 분할에서 이득 중앙값 +0.002, 체형 조건화는 −0.006이었다. §19는 날짜/촬영 조건의 영향을 확인했다. 따라서 현재 데이터에서 가장 설득력 있는 경로는 **공통 규칙 + 선택적 수준 보정 + 세트 내 개인 변화 비교**다. 이 수치는 저장된 연구 결과이며 이번 설계 작업에서 실험을 재실행한 것은 아니다.

### 3.1 운동 ID와 변형

`기본 스쿼트`와 `바벨 스쿼트`는 현재 같은 데이터 종목을 가리키지만 사용자 기준은 분리한다. 맨몸/바벨, 일반/무릎/인클라인 푸쉬업, 지지 다리, 연속 좌우 교대 여부를 기준 키에 포함한다. 다른 종목이나 장비 변형의 개인 기준을 자동 재사용하지 않는다. 기존 `Workout.postureSupported()`의 Boolean은 최종적으로 `REFERENCE_COACH`, `PERSONAL_COMPARE`, `MOVEMENT_ONLY`, `TIMER_GUIDE` 기능 집합으로 대체한다.

현재 분산된 `postureExerciseMap`, `workoutCatalog.posture`, `FloorTemporal.exercises`, `RepSignals`, `ComparisonMetrics`를 등록부에서 대조/생성한다. 새 운동이 한 군데만 등록되어 무음/빈 비교가 되는 것을 검사로 차단한다. 현재 이름/저장 기록은 alias로 유지한다.

### 3.2 피처와 단계

- 서서 운동은 현재 중력·몸 좌표계 3D 피처를 유지한다. 바닥은 현재 2D 기하 경로를 유지하며 한쪽 가시 관절을 우선하는 처리를 종목별로 확장한다.
- 단위는 프로필에 명시한다. 현재처럼 `minAmp >= 20`인지로 각도/거리 단위를 추측하지 않는다.
- 반복 비교는 같은 쪽, 같은 단계의 값을 비교한다. 무릎/팔꿈치의 좌우 평균과 `minside`만으로 왼쪽 기준을 오른쪽에 적용하지 않는다. 개별 `knee_L/R`, `hip_L/R`, `elbow_L/R` 및 필요한 2D 측별 파생값을 사용한다.
- 기본 단계는 두 극점 근방과 그 사이 이동 범위다. 기존 양 끝 15% 구간을 시작값으로 재사용한다. 추가 시간 warping/딥러닝 단계 분류기는 만들지 않는다.
- 스쿼트에서 내려갈수록 자연히 커지는 몸통 기울기를 세트 전체 평균이나 범위만으로 교정하지 않도록, **단계별 새 항목은 별도 beta 버전**으로 검증한다. 기존 세트 통계 임계값을 단계 값에 그대로 복사하지 않는다.
- 런지·컬·니업·사이드 크런치 등 교대 운동은 좌우별 기준을 만든다. 좌우 식별이 불안정하면 해당 쪽 비교를 유보하며 강제로 대칭을 요구하지 않는다.
- 반복 카운터의 35° 등의 검출폭은 정자세 최소 ROM이 아니다. 제한된 ROM을 못 세면 관측 가능한 상·하단 구간 비교/변화량 표시로 폴백한다. 없는 반복을 채워 넣지 않는다.
- 스탠딩 사이드 크런치는 현재 `RepSignals` 미등록으로 비교가 빈다. `knee_elbow_dist`의 좌우별 구간과 `torso_roll`을 후보로 추가하고, 현재 캐시에서 단계 구분을 확인한다. 미확정 단계에서는 3초 관측 창의 움직임 범위만 제공하며 “같은 반복 지점”이라고 말하지 않는다.

## 4. 개인 기준의 세 종류

초반 3회/5초는 사용자가 원래 하던 운동 안에서 자동 수집한다. 57종목마다 별도 캘리브레이션 세트를 요구하지 않는다. 교정용 3세트 가이드는 보정 허용 항목에 대한 선택 기능이며, 하지 않아도 일반 참고 기준과 개인 변화 비교는 바로 제공한다.

| 기준 | 만드는 방법 | 용도/유효 범위 |
|---|---|---|
| `observedStart` 초반 수행 | 잘 보이는 초기 3개 반복, 유지형 안정 5초. 항목별 수집 | COACH/TRACK 공통의 변화 비교. 운동 정오와 무관. 현재 세트에서 고정 |
| `guidedReference` 교정용 | 기존 기준선 가이드에서 해당 조건을 안내하고 모은 독립 3세트/기존 `baselineK` | 보정 허용 규칙만 적용. 사용자가 따라 했다는 사실이 완전한 정자세 인증은 아님 |
| `previousSession` 지난 수행 | 종료 시 저장한 기준/범위·촬영 맥락 | 이전 기록 비교. 새 세트의 정답이나 시작 기준으로 자동 대체하지 않음 |

`observedStart`는 항목별로 최소 관측 수·산포를 만족하면 수집한다. 한 항목이 불안정하면 그 항목만 수집을 연장한다. 2개 반복까지는 숫자만 미리 보여줄 수 있으나 변화 발화는 기준 확정 이후다. 교대 운동은 좌우 각각 3개를 요구하며 부족한 쪽만 “기준 수집 중”이다. 유지형은 5초·8프레임 이상과 최대 샘플 간격 조건을 함께 만족해야 한다.

**§39 플랭크 수정 방향:** `referenceEligible = 모든 항목이 공통 기준 OK`를 개인 변화 비교의 진입 조건에서 제거한다. 머리 가림 시 골반 기준은 수집할 수 있다. 초기 자세가 공통 기준을 벗어나면 COACH의 참고 안내는 계속 나오고, TRACK은 그 초기값에서의 변화만 기록한다. 이 분리는 모든 종목에 공통 적용한다.

### 4.1 개인 변화 허용폭

위상별 초기값 `b = median(초기 반복별 해당 값)`을 고정한다. 반복형 허용폭은 기존처럼 `max(피처별 측정 바닥값, 3×MAD, 이동범위 항목일 때 0.15×|b|)`를 시작값으로 쓴다. 기존 바닥값은 각도 8°, 정규화 0.06이며 이는 정확도·안전 기준이 아닌 변화 표시 설정이다. 이후 현재 캐시의 동일인 정상 반복 산포로 **피처 단위**로 바꾸되 사용자마다 오류 라벨로 학습하지 않는다.

유지형은 안정 5초 중앙값과 측정 산포를 고정한다. 초기 산포가 크면 허용폭을 무제한 넓히지 않고 해당 항목의 기준을 다시 수집한다. 소수 초반 샘플 때문에 잡음 바닥값을 낮추지 않는다. 세트가 진행되며 최근 자세로 기준을 이동시키거나 이탈을 정상 범위에 흡수하지 않는다.

기준 재설정/카메라 변경은 새 `referenceEpoch`를 만든다. 이전 변화 이력은 삭제하지 않고 어느 기준에 대한 변화인지 함께 남긴다. 좌우 가시성만 잠시 바뀐 경우는 다른 신체 측 기준으로 전환하며 이전 기준을 덮어쓰지 않는다. 같은 촬영 위치인지 확신할 수 없는 재배치는 재측정을 안내한다. 정교한 카메라 이동 자동 판별은 구현 범위에 넣지 않는다.

### 4.2 교정 기준의 개인화

개인 보정을 모든 규칙에 강제하지 않는다. 모든 종목이 개인 **변화 추적**을 갖는 것과, 모든 규칙이 개인 **정답 임계값**을 갖는 것은 다른 구현이다.

| 규칙 성격 | 처리 |
|---|---|
| `baselineEligible && baselineThresholdRel != null` 수준형 | 동일 피처·통계·도메인·촬영 맥락의 guidedReference가 있으면 `x − baseline`을 상대 기준과 비교. 원값 판정도 별도로 남김 |
| `range/std` 흔들림·고정 조건 | 중심값을 빼도 분산이 없어지지 않으므로 무조건 baseline 보정하지 않음. 같은 단계/반복의 변화를 추가로 비교 |
| 스쿼트/런지 깊이, 팔 들림 범위 등 수행 범위 | 개인의 초반 ROM은 추적 기준. 이를 근거로 공통 ROM 판정을 자동 통과시키지 않음. 제한된 범위 자체를 앱이 임상적으로 평가하지 않음 |
| 플랭크·푸쉬업 큰 분절 정렬 | 직접 정렬과 초기 대비 변화를 동시에 보존. 처짐/솟음 방향을 초기값을 빼서 지우지 않음 |
| 그립 폭·기본 몸통 기울기처럼 변형/개인차가 큰 항목 | 동일 변형 내에서 비교. 기존 eligible만 보정하며 나머지는 변화/참고 수치부터 제공 |
| 감각·힘·견갑골·요추 접지·기구 위치 등 현재 못 보는 조건 | 문장 가이드/평가 범위 표시. 다른 상관 피처를 해당 부위의 직접 관측처럼 말하지 않음 |

기존 GT에서 얻은 `threshold_rel`을 MP 값에 곧바로 정답으로 쓰지 않는다. 같은 MP 캐시에서 일반 기준 대비 보정을 비교해 적용 가능한 규칙 목록을 만든다. 부족한 조합은 기존 공통 기준과 개인 변화 비교로 즉시 동작하며, 기준선 보정을 기다리느라 운동 전체를 막지 않는다.

공통 밴드 통과를 모든 교정 기준 수집의 단일 게이트로 삼지도 않는다. 조건별 관측 자격, 가이드 수행 구간, 반대 방향 이탈 여부 등 근거를 보존한다. 초기 원값과 공통 기준이 크게 충돌하고 보정만 통과시키는 항목은 **기준 충돌**로 표시하고 자동 교정 통과/점수 개선에 사용하지 않는다. 같은 밴드로 받아들인 표본만 평가해 성능이 좋아 보이는 순환 평가를 금지한다.

## 5. 정상 표본 기준 산출

운동별 전 조건 정상 표본은 전체 자세 시각화에, 조건별 정상 표본은 해당 규칙의 수치 범위에 쓴다. 조건별 라벨과 실제 연기 설명이 다른 항목은 사용자 문구를 관측 대상에 맞춘다. `DEFINITION_QUALITY.md`에 확인된 OHP 그립 폭/전완 수직, 행잉 레그 레이즈 그립 폭/어깨-귀 거리 등의 불일치를 그대로 복제하지 않는다.

1. 원시 MP 캐시/단말 결과에서 **앱과 동일한 피처 함수**로 운동·뷰·단계별 값을 만든다. 기존 세트 집계 파일은 세트 규칙 대조용으로만 쓴다.
2. 한 수행자의 많은 프레임이 분포를 지배하지 않도록 `프레임→클립/단계 대표값→수행자 대표값`으로 집계한다. 정상 표본 참고 밴드는 p10~p90을 시작값으로 사용한다. 수행자 5명 미만이면 관측 최솟값~최댓값을 표시하고 기존 정오 임계값을 이것만으로 교체하지 않는다.
3. **보여주는 정상 표본 밴드**와 **규칙 판정 임계값**은 별도 필드다. 범위 밖이라는 이유 하나로 위반을 만들지 않는다. 새 교정 임계값은 정상 오탐과 조건별 위반 누락을 함께 대조한다.
4. 바닥 C=측면과 서서 C=정면을 운동 프로필에서 분리한다. 서서 뷰는 카메라 글자가 아니라 기존 보정된 방향 등급/`views_ok`를 따른다. 바닥 다른 카메라 높이의 밴드를 저상 측면에서 정확히 동일하다고 표시하지 않는다.
5. 정상 골격 시각화는 같은 단계의 실제 대표 표본 한 개를 골라 몸통 위치/화면 크기만 맞춘다. 서로 다른 사람의 관절 중앙값을 이어 만든 불가능한 골격, 관측 안 된 관절의 정답선, 다른 방향의 겹침은 피한다. 초기 버전은 국소 기준선/수치가 우선이다.

## 6. 화면과 음성

운동 시작 시 별도의 긴 체형 설문 없이 **촬영 위치 한 장 + 이번에 보는 부위 2~3개 + 처음 3회/5초를 기준으로 쓴다는 안내**를 보여준다. 카메라 배치는 운동 내내 한 방향을 기본으로 한다. 한 뷰에서 못 보는 항목은 접힌 범위 설명에 남기고 세트 중 다른 각도를 반복 요구하지 않는다.

| 항목 상태 | COACH | TRACK |
|---|---|---|
| 공통 참고 안 + 초기와 비슷함 | “관측한 범위 안” 또는 조용히 측정 | “초반과 비슷해요” |
| 공통 참고 밖 + 초기와 비슷함 | 지속 확인된 항목의 참고 안내. 초기부터 범위 밖이었다는 기록 | “초반과 비슷해요”. 선택 시 참고 기준 비교도 확인 가능 |
| 공통 참고 안 + 초기에서 변함 | “초반보다 이동 범위가 줄었어요” 등 관측 안내 | 같은 변화 안내 |
| 공통 참고 밖 + 초기에서 변함 | 방향이 확실한 교정 1개 우선, 초기 대비 변화는 보조 | 초기 대비 변화만 안내 |
| 측정 불가 | 해당 부위 측정 불가/촬영 안내. 다른 부위는 계속 | 동일 |
| 수치 근사만 있음 | “머리 들림 근사” 등 정확한 대상 표시 | 같은 대상의 초기 대비 변화 |

라이브 카드는 `이번 안내 1개`, `개인 비교 1~2개`, `측정 범위/누락`으로 구성한다. 모든 항목을 빨갛게 칠하지 않고 근거가 있는 부위만 강조한다. 초기 기준과 정상 참고 밴드의 색·라벨을 구분한다. 방향/단계가 맞을 때만 국소 기준선을 카메라 위에 그린다.

음성 결정기는 공통으로 하나만 둔다. 반복형 변화는 같은 방향 2회, 유지형은 1초 창 2개, 플랭크 직접 정렬의 현행 1초 지속 조건은 별도 rule 설정을 따른다. 기본 발화 간격 8초, 동일 원인 반복 20초, 복귀는 실제 발화했던 이탈의 복귀만 한 번 말한다. 화면 복귀는 3초 유지한다. 관측 중단을 복귀로 읽지 않는다. 이는 구현 기본값이며 캐시의 합성 시각으로 검증됐다고 표현하지 않는다.

서서 beta는 기존대로 관측 표시부터, 바닥은 현재 요청 범위의 명시적 참고 음성 정책을 유지한다. 새 측정 전용 운동의 음성은 “초반보다 줄었어요/늘었어요”까지다. 모델이 못 보는 척추/근긴장을 교정하는 문장을 만들지 않는다. TRACK에는 공통 기준의 교정 지시가 섞이지 않는다. 초보/숙련자 구분으로 수치 기준을 바꾸지 않는다.

종료 요약은 “개인 변화: 골반 이탈 2회, 첫 변화 24초 / 참고 기준: 고개 1항목 확인 / 미관측: 8초”처럼 출처별로 보존한다. 판정 없는 세트에 정상 점수나 “완벽”을 붙이지 않는다. 기존 점수 분모에 개인 변화/beta를 추가하지 않으며 **전체 정확도** 대신 관측한 규칙 범위임을 명시한다.

## 7. 개인화 적용 예

- **기본 스쿼트:** A가 초반보다 얕아졌는지는 A의 같은 쪽 하단/무릎각과 비교한다. B의 깊이를 A에게 강요하지 않는다. 별도의 무릎 방향 규칙은 기존 기준·촬영 방향으로 판단한다. 깊은 자세에서 자연스러운 몸통 기울기를 다른 단계와 비교해 허리 오류로 부르지 않는다.
- **플랭크:** 처음부터 골반이 참고 범위 밖이어도 관측 기준은 저장된다. COACH는 직접 정렬 참고 안내, TRACK은 “초반 대비 변화 없음”을 말할 수 있다. 둘 다 해당 자세를 정답 인증하지 않는다. 이후 정렬 선에 가까워지는 변화를 악화로 발화하지 않는다.
- **덤벨 컬:** 초반 팔꿈치 위치/팔 굽힘 범위를 그 사람 기준으로 고정한다. 계속 고정된 개인 위치와 반복 중 팔꿈치가 이동하기 시작한 현상을 구분한다. 좌우를 교대하면 각 팔의 기준을 따로 쓴다.
- **크런치:** 머리 들림의 초반/현재 차이를 제공한다. 머리 높이가 늘었다고 견갑골이 충분히 들렸거나 허리가 지면에 붙었다고 판정하지 않는다.

## 9. 현재 데이터로 하는 검증

구현 중 새 모집을 기다리지 않고 다음을 수행한다.

1. **동작 목록 검사:** 57개 전부에 프로필/지원 기능/촬영 안내/초기 기준 정책 존재. 27개 기존 자세 경로와 과거 이름이 끊기지 않는다. 하나의 조건으로 독립 규칙을 삭제하지 않는다.
2. **요구사항 사례:** 처음부터 범위 밖, 정렬 개선, 한 부위 가림, 좌우 비대칭, 초기 ROM 차이, 느림/빠름, 모드 변경, 카메라 변경, 마지막 반복, 신호 미등록을 검사한다. 초기값은 고정되고 모드별 계산은 같다.
3. **현재 데이터 대조:** 원래 엔진 / 초기 자세를 무조건 정답으로 쓰는 대조군 / 본 설계를 비교한다. 조건별 정상 오탐·위반 누락·유보를 모두 집계한다. 유보를 빼서 판정 성능만 좋아 보이게 하지 않는다.
4. **분리 단위:** 같은 수행자의 모든 카메라/클립을 한 폴드에 둔다. 초기 기준 클립과 평가 클립을 분리하고, 테스트 사용자의 초기 관측만 허용하며 위반 라벨은 보정에 쓰지 않는다. 동일인 다른 날짜가 있으면 별도 표로 낸다. 2명만 있으면 2회 교대 평가를 하고, 1명만 있으면 독립 개인 성능 대신 재생 일치 결과를 낸다.
5. **새 숫자 선정:** 새 임계값/보정 후보는 훈련 폴드 안에서만 선택한다. 반복/카메라를 표본 수처럼 부풀리지 않고 사람별로 평균낸다. 개선이 일관되지 않는 보정은 비활성으로 두고 개인 비교 기능은 제공한다. 목표는 경고 감소 자체가 아니라 기존 오탐 감소와 누락 증가 여부의 동시 확인이다.
6. **시간 검증:** AIHub 성긴 프레임의 임의 600ms는 자세/단계 대조용이다. 템포·1초 지연·마지막 반복은 실제 시각의 기존 기기 로그와 합성 요구사항 시퀀스로 별도 검사한다. 시간 정답이 없는 영상에서 피로나 반동 원인을 정답으로 만들지 않는다.
7. **단말:** 저장된 좌표 재생으로 수치/결과 일치 → 필요한 기존 이미지의 Android 추론 재생 → UI/TTS 상태 로그 대조 순서다. 전체 데이터셋을 매 수정마다 재추론하지 않는다.

현재 300ms 샘플 주기와 기존 MediaPipe 모델을 유지한다. 새 비교 연산은 항목당 상수 시간 갱신과 작은 고정 버퍼로 처리한다. 30초 이하/최대128샘플 창, 원시 영상 추가 저장 없음, 새 로직의 샘플당 처리 5ms 이하를 구현 목표로 둔다. 성능 수치는 구현 후 단말에서 확인할 목표이며 달성 실측값이 아니다. 빠른 유산소/복합 운동은 3.3fps에서 보이지 않는 접촉/회전을 만들어내지 않는다.
