# 바닥 8종목 실기기 검증

목적은 정상 자세를 앱이 인증하는 것이 아니라 관측 시간·이탈 이벤트·반복별 범위·유보·문구가 일치하는지 확인하는 것이다. 전부 beta이며 점수·교정 음성이 없어야 한다.

폰을 몸의 옆, 바닥에 가까운 고정 거치대에 두고 머리·손·무릎·발목 전체를 담는다. 정면/뒤는 이 평가를 검증하는 권장 배치가 아니다. 좌우 측면을 각각 촬영해 가림 차이를 확인한다. 바닥 C와 서서 C의 의미는 다르다.

| 종목 | 측면 한쪽당 시행 | 확인 |
|---|---|---|
| 플랭크 | 20초 유지 1세트, 자연스럽게 자세 변화가 생긴 20초 기록 1세트 | 초기 5초 안정 수집, 측정 시간, 첫 2초 지속 이탈 시각/방향을 영상 또는 관찰자 시각과 대조 |
| 푸시업·니푸쉬업 | 각 6회 × 2세트 | 매 반복을 관찰자가 기록하고 하단 피처·검출 수·범위 미달 수 대조 |
| 힙쓰러스트 | 6회 × 2세트 | 각 상단 최대값, 검출 수, 고개 각도 참고 기록 확인 |
| 크런치·Y 레이즈 | 각 6회 × 1세트 | 견갑골/목 판정이 없고 머리/팔 들림 근사만 있는지 확인 |
| 레그 레이즈·시저 크로스 | 각 6회 또는 교대 20초 × 1세트 | 투영 무릎각·높이 근사, 고개 참고, 허리 접지 미판정 확인 |

양쪽 측면 전체 24세트. 무리한 실패 자세를 만들지 않는다. 쉬어 가며 촬영하고 실제 자세 정답은 관찰자/영상 라벨로 별도 기록한다.

추가 3세트: (1) 측정 중 3초 화면 밖 → 빠진 시간이 정상 시간에 더해지지 않아야 함, (2) 5초 미만 플랭크 → 초기 구간 유보, (3) 일정 반복 6회 뒤 10초 정리 → 원본 프레임은 남고 평가 종료 시각은 마지막 검출 + 한 주기여야 함. 불규칙 반복에서는 자동 컷을 보장하지 않는다.

로그는 기존 pull_logs.py로 회수한다. set_id로 자가 라벨과 연결하고 `measurements`, `anchor_t_ms`, `assessment_end_t_ms`, 원본 프레임과 반복 극값을 확인한다. 추후 보정은 3~6명 이상으로 사람별 학습/검증을 분리하고 조건별 오탐률·검출률·유보율·시간 오차를 함께 보고한다. 정답 라벨을 수집하기 전에는 '정확도 향상'을 주장하지 않는다.
