## 무엇을 하는 앱인가요?

**촬영/영상 가져오기 → 원본 보존 → 관절 좌표 추출 → 사람이 정답 표시 → 엔진 비교 → 자료 내보내기**

| 기능 | 역할 |
|---|---|
| 운동 촬영·영상 가져오기 | 기기 카메라 앱으로 촬영하거나 기존 영상을 앱에 복사합니다. |
| 실제 시간·좌표 보존 | 영상 프레임의 실제 PTS, 추정 관절 좌표와 가시성, 모델 해시를 저장합니다. |
| 독립 정답 입력 | 영상에서 반복 구간·좌우, 플랭크 유지 구간, 자세 항목별 정상·오류·판단 불가를 사람이 표시합니다. |
| 정답 이력 관리 | 초안을 복구하고 수정할 때마다 새 개정을 저장합니다. 처음 정답을 확정하기 전에는 엔진 예측을 숨깁니다. |
| 동일 입력 엔진 비교 | 같은 좌표를 구형 반복 코어와 v2에 넣어 누락·추가·완료 시각 오차를 비교합니다. |
| 자세 평가 | 사람이 라벨한 시간에서 항목별 오탐·오류 검출·판정 가능 범위를 함께 계산합니다. |
| ZIP 내보내기 | 원본 영상, 좌표, 정답 개정, 엔진 결과, 파일별 SHA-256을 한 묶음으로 저장합니다. |

**목적은 엔진 개발에 쓸 재현 가능한 자료와 평가 결과를 만드는 것입니다.** 이 앱을 설치하거나 촬영을 끝냈다는 사실만으로 운동 자세의 정확성이 검증되지는 않습니다. 수집 중에는 교정 음성을 재생하지 않습니다.

## 처음 사용하는 순서

1. **수행자 코드와 촬영일**을 입력합니다. 실명 대신 `P001` 같은 코드를 사용하고 자료 용도(학습·보정·최종 시험)를 선택합니다. 같은 사람은 다른 날에도 같은 분할을 사용합니다.
2. **운동·수행 방식·촬영 방향**을 선택합니다. 바닥 운동은 측면 촬영을 확인하고 데드리프트는 바닥 출발 여부를 지정합니다.
3. 촬영 대상의 동의를 확인한 뒤 **운동 촬영** 또는 **영상 가져오기**를 누릅니다. 카메라 앱에서 녹화를 마치고 저장/확인합니다. 첫 사용은 짧은 영상으로 진행하세요.
4. 영상 상세에서 **관절 좌표 추출**을 실행합니다. 분석은 녹화가 끝난 뒤 수행됩니다.
5. **영상 보며 정답 표시**에서 평가 구간과 반복/자세 정답을 입력하고 **정답 개정 저장**을 누릅니다. 반복이 0회여도 직접 검토 확인해야 합니다.
6. **같은 좌표로 엔진 비교 → 비교 결과 열기**를 누릅니다. 정답을 수정했다면 다시 비교합니다.
7. **영상·좌표·정답·결과 ZIP 저장**으로 파일을 보관합니다. 원본 영상은 이후 모델을 바꿔 재추론할 때 다시 사용할 수 있습니다.

1회 영상은 10분 이내, 가져오기는 2GB 이내입니다. 앱의 원본은 자동 업로드·자동 만료 삭제되지 않습니다. 기기 자료 삭제는 영상 상세에서 직접 할 수 있으며, 따로 내보낸 ZIP은 유지됩니다.

## 비교 결과는 어디까지 믿을 수 있나요?

- **반복 비교:** `v1.1.0-preview.2` 태그 소스에서 보존한 반복 코어와 현재 제품의 v2 엔진을 비교합니다. 구형 APK 전체의 카메라·IMU·화면·음성을 재현하는 것은 아닙니다.
- **자세 비교:** 공통 규칙의 `ship/window` 기준선과 v2 피드백 정책을 비교합니다. 유보·미지원은 정상으로 채우지 않고 판정 범위를 함께 표시합니다.
- **좌표와 정답:** 관절 좌표는 MediaPipe의 추정 결과입니다. 실제 사람의 정답은 영상을 검토해 별도로 입력해야 합니다.
- **시간:** 실제 영상 PTS를 쓰며 약 5Hz로 좌표를 추출합니다. 개별 프레임의 절대 촬영 UTC와 실시간 음성 전달 지연을 측정하는 앱은 아닙니다.
- **최종 시험:** 예측을 본 뒤 정답을 수정하면 해당 이력을 남깁니다. 시험 결과에 맞춰 엔진을 계속 조정한 경우 새 시험 자료가 필요합니다.

## 확인한 것과 남은 검증

**JVM 514건, Android 에뮬레이터 검사 5건 통과.** 가변 시각 MP4, 실제 MediaPipe 추출, 정답 저장, 재생 결과의 동일성, 해시 변조 거부, ZIP 내보내기와 화면 조작을 확인했습니다.

실제 사람의 자세 정확도, 물리 휴대폰의 카메라·디코더 호환성, 장시간 발열, 음성 안내 후 교정 효과는 아직 검증하지 않았습니다. 자동 검사 통과를 운동 정확도로 해석하지 않습니다.
