# TREX v2 — 26종 운동 관측과 자세 교정

이 README는 **`feature/pose-evaluation-engine` 브랜치의 두 번째 앱 버전 `trex_v2`**를 소개합니다. 기존 TREX의 운동 계획·식단·기록 화면에 이 대화에서 개발한 새 동작 관측 엔진을 연결했습니다. 독립 검증용 `TREX 실험실`과는 다른 앱입니다.

**25종 반복 횟수 + 플랭크 관측 시간**을 지원합니다. 그중 **16종·30개 관측 항목**에서 제한된 교정 음성과 참고 점수를 제공합니다. 26종 모두의 자세를 완전히 판정한다는 뜻은 아닙니다.

두 버전 모두 MediaPipe 관절 추론을 기반으로 합니다. **v2는 새로운 동작 처리·피드백 정책을 적용한 버전이며, 완전히 새로 학습한 AI 모델이 아닙니다.** 실제 사람의 정확도나 만족도가 첫 버전보다 높아졌다는 결론은 아직 내리지 않았습니다.

스쿼트에서 무릎 방향을 잘못 단정하던 대리 규칙, 데드리프트에서 손 위치로 바벨 밀착을 추정하던 규칙을 교정·점수에서 제외했습니다. 몸통 기울기를 척추가 말렸다고 표현하지 않고, 실제 측정한 항목으로 안내합니다. 이는 해당 오류를 모두 더 잘 검출한다는 의미가 아니라 **근거가 부족한 판정을 하지 않도록 범위를 제한한 변경**입니다.

## 설치하고 운동하기

1. Android 휴대폰에서 위 **v2 APK**를 내려받아 엽니다. 필요한 경우 해당 브라우저·파일 앱의 설치 출처를 허용합니다.
2. **trex_v2**를 실행하고 운동 계획에 원하는 종목을 추가합니다. 카메라를 사용하는 운동은 카메라 권한을 허용합니다.
3. 준비 화면의 종목별 촬영 안내에 맞춰 몸을 담습니다. 바닥 운동은 측면 촬영 확인이 필요합니다.
4. 준비 설정에서 **교정 음성 · 점수 / 기록** 모드를 고릅니다. 새 버전 첫 진입은 교정 모드와 음성이 켜진 상태입니다. 음성 버튼으로 끌 수 있습니다.
5. 시작 위치에서 잠시 멈춘 뒤 운동합니다. 관측 가능한 첫 완결 반복 이후 연속된 관측 창을 모아 교정·점수를 표시합니다.
6. 실제 횟수가 다르면 **횟수 수정**으로 입력하고, 운동을 마치면 **세트 완료**를 누릅니다. 관측 원본과 직접 입력값은 별도로 보존합니다.

데드리프트는 준비 설정에서 **선 자세 출발 / 몸을 숙여 출발**을 선택할 수 있습니다. 선택 범위를 비워 두면 관측 반복만 셉니다. 입력한 범위는 개인 목표이며 올바른 자세의 기준으로 인증하지 않습니다.

## 교정 음성과 점수를 읽는 방법

- **교정 모드:** 관측한 항목의 참고 점수와 음성을 제공합니다. 같은 항목의 반복 안내에는 간격을 둡니다.
- **기록 모드:** 자동 관측·기록을 사용하고 교정 음성·점수는 표시하지 않습니다.
- **점수 없음:** 판정할 수 없다는 뜻입니다. 정상이나 100점으로 처리하지 않습니다. beta·exclude 항목은 점수와 음성에서 제외합니다.
- **실시간 점수:** 현재 관측 창에서 참고 범위 안에 있는 항목 / 판정한 항목 × 100입니다.
- **세트 점수:** 세트 중 연속 관측으로 확인한 이탈을 보존합니다. 실시간 점수와 집계 구간이 다릅니다.

참고 점수는 전신 자세의 정확도나 안전 점수가 아닙니다. 첫 버전과는 판정 범위가 다르므로 숫자만으로 우열을 비교할 수 없습니다. 저장된 개인 기준선을 자동으로 빼서 임계값을 보정하지 않습니다.

## 기록과 검증 상태

운동·식단 데이터는 기기에 저장됩니다. 로그인은 서버 인증에 연결되지 않은 체험용이며 음식 사진 자동 분석은 제공하지 않습니다. 최근 7일 운동 기록 정책을 사용합니다.

기본 자세 로그는 세트 요약입니다. 준비 설정에서 해당 세트의 진단 저장을 켜면 원본 관절 좌표·피처·시각을 앱의 백업 제외 영역에 저장합니다. 진단 좌표는 7일/20MB 한도로 보관하며 영상 저장·업로드·자동 학습은 하지 않습니다.

공유 엔진 95건과 앱 396건의 JVM 검사, 이전 설치본의 실기기 흐름·추론·TTS 검사 4건이 통과했습니다. 이는 **실제 사람의 26종 횟수 정확도·교정 효과 검증과 다릅니다.** 다운로드 APK의 빌드 검사와 서명·해시는 [v2 배포 문서](docs/ANDROID_V2_RELEASE.md)와 릴리스에서 확인할 수 있습니다.

## 개발 및 상세 문서

```powershell
git clone --branch feature/pose-evaluation-engine https://github.com/LeeDongHyun00/TREX.git
cd TREX
.\gradlew.bat :pose-engine:test :app:testDebugUnitTest :app:assembleDebug
```

JDK 17 이상과 Android SDK 36을 사용합니다. Android Studio에서 저장소 루트를 열고 `app`을 실행하면 **trex_v2**입니다. APK 출력 경로는 `app/build/outputs/apk/debug/app-debug.apk`입니다. `local.properties`는 각자 SDK 위치에 맞게 설정합니다. APK·키스토어·개인 로그는 Git에 커밋하지 않습니다.
