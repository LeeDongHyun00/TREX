# TREX Design Guide

## 1. 프로젝트 한 줄 정의

TREX는 운동 초보자가 부담 없이 따라 하면서, 자신의 자세를 바로 이해하고 바로 고칠 수 있게 돕는 운동 자세 교정 앱이다.

## 2. 핵심 컨셉

### 컨셉 키워드

- 정확함
- 안정감
- 쉬운 코칭
- 꾸준한 반복

### 브랜드 메시지

TREX의 디자인은 "어렵지 않게, 바로 고치게"에 집중한다.

앱 전반에서 아래 핵심 문구를 반복적으로 사용한다.

- `바로 보고`
- `바로 고치고`
- `TREX와 운동 시작`

위 문구는 온보딩, 홈, 운동 시작 버튼, 결과 요약, 빈 상태 화면 등에서 반복 사용한다.

## 3. 페르소나

### 주요 사용자

- 운동을 막 시작했거나, 자세에 자신이 없는 초보자
- 연령대는 20대부터 40대
- 헬스장 기구 사용법보다 "내가 지금 제대로 하고 있는지"를 더 궁금해하는 사용자

### 사용자 특성

- 복잡한 수치보다 한눈에 이해되는 피드백을 선호한다
- 너무 강한 전문가 톤보다 친절하고 명확한 코칭 톤을 선호한다
- 실패를 지적받는 느낌보다, 바로 수정할 수 있다는 느낌을 원한다

## 4. 디자인 방향

### 톤앤매너

- 친절하지만 가볍지 않다
- 전문적이지만 위압적이지 않다
- 운동 앱답게 에너지가 있지만, 초보자를 배려해 안정감이 먼저 느껴져야 한다

### 화면 인상

- 첫인상은 "믿을 수 있는 코치"
- 사용감은 "지금 바로 따라 할 수 있는 간단한 가이드"
- 결과 인상은 "혼난 느낌"이 아니라 "조금씩 좋아지고 있다"는 감각

## 5. 컬러 시스템

### 메인 컬러

- Primary Green: `RGB(117, 152, 72)`
- Hex: `#759848`

이 색은 TREX의 대표 색으로 고정한다. 화면에서 사용자가 가장 많이 기억해야 하는 색이다.

### 권장 컬러 역할

- Primary: `#759848`
- Primary Deep: `#5F7D39`
- Primary Soft: `#A8C47C`
- Background: `#F5F7F1`
- Surface: `#FFFFFF`
- Text Primary: `#1F2618`
- Text Secondary: `#5E6754`
- Success: `#4E9F5A`
- Warning: `#D78B28`
- Error: `#C65454`

### 컬러 사용 원칙

- CTA 버튼, 진행 상태, 핵심 강조는 반드시 `#759848` 계열을 사용한다
- 화면마다 초록 계열 포인트가 반복적으로 보여야 TREX 인지가 쌓인다
- 강한 경고색 남용은 피하고, 초보자가 긴장하지 않도록 경고는 제한적으로 쓴다

## 6. 반복 요소 규칙

사용자가 앱을 기억하기 쉽게 아래 두 가지를 반복한다.

### 반복 색

- 메인 액션 버튼
- 운동 시작 버튼
- 진행률 바
- 현재 자세 상태 배지
- 주요 아이콘 포인트

위 요소에는 `#759848` 또는 같은 계열 톤만 사용한다.

### 반복 문구

아래 문구 체계를 앱 전체에서 일관되게 유지한다.

- 시작 전: `바로 보고`
- 운동 중: `바로 고치고`
- 완료 후: `TREX와 운동 시작`

필요 시 문장형으로 확장한다.

- `바로 보고, 자세를 확인하세요`
- `바로 고치고, 다음 동작으로 넘어가세요`
- `TREX와 운동 시작, 오늘도 정확하게`

## 7. UI 스타일 원칙

### 레이아웃

- 복잡한 카드 나열보다 1개의 핵심 행동에 집중하는 구조
- 한 화면에 주요 CTA는 1개만 가장 강하게 보여준다
- 초보자용 앱이므로 정보 밀도보다 이해 속도를 우선한다

### 버튼

- 주 버튼은 넓고 분명해야 한다
- 버튼 문구는 행동 중심으로 짧게 쓴다
- 예시: `운동 시작`, `자세 확인`, `다시 따라하기`

### 카드와 패널

- 둥근 모서리와 여백을 충분히 사용한다
- 지나치게 기술적인 대시보드 느낌은 피한다
- "운동 코칭 카드"처럼 보이게 설계한다

### 아이콘과 그래픽

- 직관적인 신체, 동작, 체크, 방향 아이콘 중심
- 초보자에게 낯선 추상 아이콘은 피한다
- 관절, 자세, 카메라, 진행 상태가 바로 이해되어야 한다

## 8. 카피라이팅 가이드

### 문장 톤

- 짧고 분명하게 쓴다
- 지시보다 안내처럼 들리게 쓴다
- 실패보다 수정 가능성에 초점을 둔다

### 좋은 예시

- `무릎 높이를 조금 더 올려보세요`
- `상체를 조금만 곧게 유지해보세요`
- `좋아요. 지금 자세를 유지해보세요`
- `다음 동작도 바로 확인해볼까요?`

### 피해야 할 예시

- `자세가 틀렸습니다`
- `잘못된 동작입니다`
- `기준 미달입니다`

## 9. 추천 화면 구조

### 홈

- 한 줄 메시지: `바로 보고, 바로 고치고`
- 오늘의 운동 시작 CTA
- 초보자용 추천 운동 1개 또는 2개

### 운동 준비

- 카메라 위치 안내
- 운동 자세 예시
- 시작 전 체크포인트 3개 이하

### 운동 진행

- 현재 자세 상태
- 실시간 한 줄 코칭
- 반복 횟수
- 진행 상태

### 결과

- 잘한 점 먼저 노출
- 다음에 고칠 1~2개 포인트만 제안
- 다시 하기 / 다른 운동 시작 CTA 제공

## 10. 금지 사항

- 어두운 배경 위에 네온 컬러만 강하게 쓰는 과한 헬스 앱 스타일 금지
- 너무 많은 전문 용어 사용 금지
- 한 화면에 경고 메시지를 여러 개 동시에 노출하는 방식 금지
- 초보자가 실패했다고 느끼게 하는 공격적인 피드백 금지

## 11. 최종 디자인 문장

TREX는 "강한 운동 앱"보다 "계속 켜고 싶은 자세 코치 앱"처럼 보여야 한다.

기억 포인트는 단순해야 한다.

- 색은 `#759848`
- 문구는 `바로 보고, 바로 고치고`
- 인상은 `친절한 자세 코치`
